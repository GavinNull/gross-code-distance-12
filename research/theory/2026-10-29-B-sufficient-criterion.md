- 日期：2026-10-29（2026-10-30 按审计修订）/ 执行者：theory agent（问题 B）/ 审计：`research/audits/2026-10-29-theoryB.md`（无推翻，按其意见改了 5 处陈述）
- 代码：`search/theory/B/`；原始输出：`results/theoryB/`（不进 git）
- 范围：单辅助比特、CNOT 模板、周期调度（允许回绕）、SD6，按基底分开（Z 基底只看 X 型误差与 Z 校验探测器；评估器在 Z memory 里本来就只有 Z 校验探测器，所以这里不是放宽而是等式）。

## 结论先说

1. **精确约化。** 把电路距离问题改写成"台阶配对"：每个落到数据比特上的误差，对每个读它的校验只留下一个整数，就是该校验第几个实例第一次看到它；一组故障不被探测，当且仅当每个读者收到的整数两两配对（每个值出现偶数次）。这个模型与评估器的 SD6 DEM 逐个签名相等（u11、c11、bb18、bb108 模板、ctl_p10，R = 1–3，两基底，集合完全相同）。
2. **不可分段 = 上同调非零。** 对每对共享数据比特的 X 校验 c、Z 校验 z，定义 δ(c, z) = z 的第几个实例最先看到 c 的第 0 个实例沉积的误差（确定性保证在共享比特上取值一致）。（|Q| = 2 时）电路在体内可分段当且仅当 δ 是上边缘 b_z − a_c；此时每个扩展码逻辑都在体内提升，体内 d_circ ≤ d_ext。对 SBB 的非交错电路（评估器标号下 δ 为常数），同一论证对所有 R 成立，就是 SBB Cor. 1 的两行证明。δ 的上同调类非零是体内 d_circ > d_ext 的必要条件，但不足以给出 d_circ = d：IBM depth-8（gross）的 δ 也不是上边缘，d_circ 只有 10 = d_ext < 12。
3. **窗口引理去掉了间隙论证。** 若评估器展开的有限电路满足两个与 R 无关的边界条件（第 −1 个读者实例都在时刻 0 之前读，第 R 个读者实例都在最后一层之后读），有限 R 的不可检测故障集包含于体内不可检测故障集（同样的列）。u11、c11、bb18_n8_d4 三个电路都满足；但这两个条件必须逐个电路核对（审计的 80 个随机调度×基底实例中 61 个不满足），它们是否必要尚不清楚。于是**判据**（d ≤ d_ext + 2、窗口条件、无零像钩子）：权重 d_ext … d−1 的每个扩展码逻辑（按推广的 Lemma 2 带上允许的零像故障）在体内都提升不了，就对**所有** R 有 d_circ = d。这把原证明里"R ≤ 31（或 25）逐轮 lift + 间隙论证"换成了一个与 R 无关的有限计算。
4. **提升失败的原因可以写成一个环。** 固定实现方式与配对方式后，体内提升是一个差分约束系统，不可行当且仅当约束图有负环；负环就是一条读者链，沿着它累加 δ 的差（和乐）超过了途经数据列能提供的松弛。最简单的证书只用两个钩子：两个钩子 f、g 有两个"私有读者"（S 中只有 f、g 击中它们），一个读者认为 f 晚一个实例，另一个认为 g 晚一个实例，任何相对轮次平移都不能同时满足，和乐 = 2。**u11 的全部 144 个权重 10 扩展逻辑都有这样一个两钩子证书**（两基底），Fig. 1(b) 的例子里是 Z58 与 Z60 夹住 X45、X59。
5. **为什么这三个电路成立**：u11 与 c11 的 δ 都是"单项扭转"：δ 只在包含某一项（u11 是 B1，c11 是 A2）的 X–Z 对上差 1。这个结构来自同一个计时模板：X 的最后一个 CNOT 和 Z 的第一个（回绕的）CNOT 落在同一项上。权重 d_ext 的逻辑全部被只含钩子的环卡住（u11 144/144，c11 405/585，其余 180 个需要数据列的松弛或配对分支，精确求解器全部判否）；权重 d_ext+1 的逻辑大部分（u11 5400/7344，c11 13410/16830）也是钩子环，其余由精确求解器判否。bb18 不平移不变，且有 5 对 X、Z 校验支撑完全相同（共享 6 个比特），δ 在这 5 对上取两个值，所以在 bb18 上 δ 不是一个 1-余链；精确求解器在权重 2（+1 零像）、3 全部判否。
6. **构造**：u11 的计时模板与码无关，对任何 A、B 各三项的 BB 码都合法且确定。直接套到 **[[108,8,10]]**：d_ext = 8，权重 8（+1 翻转）的 54 个、权重 9 的 2268 个扩展逻辑两基底体内都提升不了，窗口条件成立，所以**任意 R、两基底 d_circ = 10**；项目的独立 DEM 精确搜索 ccsearch 在 R = 1、2 两基底确认无权重 ≤ 9，R = 1 找到权重 10。套到 [[90,8,10]] 则失败（体内有 45 个权重 9 逻辑提升，距离 ≤ 9），所以模板不是万能的，项的标号（哪一项被扭转、顺序类）要随码选。[[72,12,6]] 在这个顺序类下 d_ext 已经是 6，没有信息量。

判据仍然要列出轻扩展逻辑，不是一条只看电路局部的不等式；这一点在第 8 节说明。

## 1. 设定

周期 P；每个校验的第 j 个实例在其第 0 个实例的时刻上加 jP。Z 基底：写者 = X 校验（辅助比特是控制位，第 k−1 个 CNOT 之后辅助比特上的 X 在第 k..6 个 CNOT 的时刻沉积到 q_k..q_6），读者 = Z 校验（第 t 个实例在 ρ_z(q) + tP 读 q）。X 基底交换角色。

数据比特 q 在时刻 u（半整数）获得一个误差，读者 z ∋ q 的**台阶指标**是 σ_z(q, u) = min{t : ρ_z(q) + tP > u}。

## 2. 台阶配对模型

**定理 1。** 第 t 次测量 m_t 等于台阶指标 ≤ t 的沉积的个数（模 2）加上该实例的测量翻转。指标为 s 的一项恰好翻转探测器 d_s = m_s + m_{s−1}（s = R 时是最后的数据读出探测器）；第 t 个实例的测量翻转等于两项 {t, t+1}。所以一组故障不被探测，当且仅当每个读者收到的指标多重集里每个值出现偶数次；它翻转的逻辑就是残余数据误差的 L 像。

*证明。* 用 SM S2 的 (a)(b)(c)：数据上的 X 不离开；Z 校验辅助比特上的 X 不回到数据；X 校验辅助比特上的 X 只沉积到后缀上。m_t 是 supp z 在读时刻的 X 奇偶，所以 m_t = Σ[σ ≤ t]。d_s 只在 s 处翻转。剩下要说明每个 SD6 单故障分量（的 X 部分）恰好是模型里的一个故障，下表逐类列出（Z 基底；X 基底交换 X↔Z 与校验类型）：

| SD6 位置 | X 部分 | 模型中的故障 |
|---|---|---|
| X 校验第 k 个 CNOT 之后（辅助控制，数据 q_k） | X_a | 钩子，后缀 q_{k+1}..q_6（k = 6 时为空） |
| 同上 | X_q | q_k 上、该 CNOT 之后半层的数据误差 |
| 同上 | X_a X_q | 等于该 CNOT 之前的 X_a，即后缀 q_k..q_6 的钩子 |
| Z 校验 CNOT 之后（数据控制 q，辅助目标 b） | X_q | q 上、该 CNOT 之后的数据误差（此读者已读过它） |
| 同上 | X_b | 该实例的测量翻转 |
| 同上 | X_q X_b | 等于该 CNOT 之前的 X_q，即读之前的数据误差 |
| 数据比特空闲 / 数据复位后 / 最终读出前 | X | 对应半整数时刻 / 时刻 ½ / 最后一层之后的数据误差 |
| X 校验辅助：RX 之后、第一个 CNOT 之前（含空闲） | X | k = 1 的"钩子"，沉积整个 X_c，签名为空（引理 2） |
| X 校验辅助：两个 CNOT 之间空闲 | X | 对应后缀的钩子 |
| X 校验辅助：测量前 / 复位后的翻转 | Z 型 | 无 X 部分，Z 基底无影响 |
| Z 校验辅助：复位后、空闲、测量前 | X | 该实例（或下一实例，取决于位置）的测量翻转 |

反过来，模型的每个故障都有 SD6 位置实现（数据比特每层都空闲或参与 CNOT，所以每个半整数时刻都有数据故障位置）。□

单故障只有三类：数据误差（任何半整数时刻，每层都有空闲或 CNOT 故障位置）、钩子（写者实例 j、后缀起点 k = 2..6）、测量翻转。`validate.py` 把模型的签名集合与评估器 stim DEM 的签名集合逐个比较：u11、c11 R = 2、3，bb18 R = 2，bb108 模板 R = 2，ctl_p10 R = 1，两基底全部相等（例如 u11 R = 2 每基底 1584 = 1584）。

## 3. δ 余链与可分段性

**引理 2（配对）。** 写者辅助比特在第一个 CNOT 之前的 X 作用在 |+⟩ 上是恒等，因此它沿六个 CNOT 沉积的整套 X_c 不能触发探测器：对每个读者 z，c 与 z 共享比特上的指标两两配对。|Q| = 2 时两个指标相等，记为 δ(c, z)。

于是 δ 是 X–Z 重叠二部图 G_XZ 上的整数 1-余链。平移不变的 BB 调度里，z − c = A_i + B_j，两个共享比特是"X 的 A_i 对 Z 的 B_j"和"X 的 B_j 对 Z 的 A_i"，δ 只依赖 (i, j)，是一个 3×3 整数矩阵；平移不变的 δ 是上边缘当且仅当 9 个值相等（对平移群求和即得）。

**命题 3（体内命题）。** 设所有重叠 |Q| = 2（BB 码 gross、[[90]]、[[108]] 如此；bb18 不满足，见表）。(a) 电路在体内可分段（每轮的 X 实例在共享比特上都夹在同轮前后的 Z 实例之间）⇔ δ = b_z − a_c。(b) 此时每个扩展码逻辑 S 都在体内提升：钩子取平移 a_c，数据误差放在该比特第一个 X CNOT 之前（δ ≡ 0 时所有读者都给同一指标），于是每个读者收到的指标都等于 b_z，个数等于 (H_Z S)_z，为偶数。所以体内 d_circ ≤ d_ext。(c) 若评估器标号下 δ 为常数且势全为 0（SBB 的非交错电路），(b) 的构造只用同一轮的实例，对每个 R ≥ 1 都存在，所以对所有 R 有 d_circ ≤ d_ext，这就是 SBB Cor. 1。一般的可分段流水电路，势 a_c 各不相同，有限 R 版本还需要这些实例存在以及窗口条件，这里不声称。

*证明。* (a) 重新标号 X 实例 j → j + a_c、Z 实例 t → t + b_z 等价于把 δ 减去上边缘；δ ≡ 0 正是"X_j 在 Z_{j−1} 之后、Z_j 之前"。(b) 数据比特 q 上若 δ(c, z) = 0 对所有含 q 的 c、z 成立，则 q 的所有 X CNOT 时刻都在 (ρ_z(q) − P, ρ_z(q)) 内，取其中第一个之前半层即可。□

| bb108 u11 模板 | 0 ×162，−1 ×324 | 否 | 10 = d（本文） |
| bb18_n8_d4 | 0/1；5 对支撑相同的校验上取两个值 | 不适用（δ 不是 1-余链） | 4 = d |

## 4. 窗口引理

**引理 4。** 设评估器展开（`candidate.unroll`）给出每个校验第 0 个实例的起点。若
(Wb) 每个读者的第 −1 个实例都在时刻 ≤ 0 读完，
(Wt) 每个读者的第 R 个实例都在最后一层之后才读，
则有限电路中每个沉积（任何存在的写者实例、任何半整数时刻的数据误差）的有限台阶指标等于体内台阶指标。因此有限 R 的每个不可检测故障集都嵌入体内，是同样列的体内不可检测故障集（有限 ⊆ 体内）。反方向一般不成立：体内可以用 0..R−1 以外的实例。定理 5 只用包含方向。

*证明。* 有限指标 = 该实例之前在 0..R−1 中读过的次数（读满则为 R，即最终读出）。沉积时刻 u ∈ [½, last + ½]。(Wb) 给出 read_{−1} ≤ 0 < u，(Wt) 给出 read_R > last ≥ u，所以体内指标落在 [0, R] 内，与有限指标相等。□

两个条件都与 R 无关（展开选的全局平移不随 R 变）。`window.py` 还对 R = 1..3 逐个沉积比较有限与体内指标：u11、c11、bb18_n8_d4、c16、u16、bb108 模板两基底 0 处不一致。反例：ctl_p10 的 X 基底 (Wt) 不成立（72 处不一致），Z 基底成立；Z 基底有限 R = 1 提升的 432 个权重 11 逻辑全部包含在体内提升的 432 个里（`finite.py --compare-bulk`）。

这两个条件不是普遍成立的，必须逐个电路核对：审计用 u11 顺序类、周期 8–14 的 40 个随机合法确定调度做了检验，80 个调度×基底实例中 61 个不满足 (Wb) 或 (Wt)。目前没有找到"窗口不成立而有限 R 比体内多出提升"的实例，所以不知道它们是否必要；它们只是证明所需的充分条件。

为什么必须检查：若第 −1 个读者实例在时刻 0 之后读（例如把 u11 的 Z 窗口放在 X 窗口之后展开），第 0 轮 X 实例的沉积会被"截断"成同一个指标，等于边界处局部分段，体内的障碍在边界上可能消失。评估器的展开恰好选了让 Z 实例先开始的平移，所以 u11、c11 没有这个问题。

## 5. 判据

**定理 5。** 假设：(1) d ≤ d_ext + 2；(2) (Wb)(Wt) 成立；(3) 没有 H‖L 像为零的钩子后缀（k = 2..6），因此零像机制只有测量翻转（u11、c11、bb108、bb18 都核过）。若每个权重 d_ext 的扩展码逻辑 S（不加，或加 1 个测量翻转）以及每个权重 d_ext + 1 的扩展码逻辑（d = d_ext + 2 时）在体内都不能提升，则对所有 R ≥ 1、该基底 d_circ ≥ d；数据复位后施加一个权重 d 的数据逻辑不触发探测器，所以 d_circ = d。

一般情形（d ≥ d_ext + 3）的缺口，本文没有补全：(i) 相同列对可以是 S 以外的任意列；(ii) 可以有两对以上相同列；(iii) 可以有两个以上翻转，也可以在同一读者上；(iv) |S| ≥ d_ext + 3 时列表必须包含可约集合（逻辑与平凡零 H 和集合的并），而"遇到 H 和为 0 就停"的 DFS 只在 |S| < d_ext + 3 时完备。

*证明。* 有限 R 的不可检测集由引理 4 是体内不可检测集；把每轮指标都映到 0（"一轮时间圆"）就是 Lemma 1 的伸缩求和，得到一个扩展码逻辑，计数同推广的 Lemma 2：w 个故障 = 不同非零像（权重 ≥ d_ext）+ z 个零像 + c 对相同像。由于 d − 1 ≤ d_ext + 1，c = 0，z ≤ 1，所以只剩假设里列出的情形。□

两点附注：
- 把指标模 N 而不是模 1，得到"N 轮时间圆"上的电路；体内不可检测集投影到每个时间圆，所以每个 N 都给出 d_circ 的下界，N = 1 是扩展码。u11：N = 2 时 144 个权重 10 全部提升，N = 3 时全部不提升（对应和乐 2），但 N = 3 时仍有 936 个权重 11 提升，所以小 N 不够，判据里用的是体内（精确）。
- 定理 5 的计算与 R 无关。原证明的间隙论证（G = 31 → R' = 31）在窗口条件下不再需要。

## 6. 提升 = 差分约束；和乐证书

固定每列的实现方式（合并列可能有数据与钩子两种实现）、每个被 2m 项击中的读者的配对方式、翻转的位置后，变量是 y(j, z)（列 j 在读者 z 处的指标）：
- 钩子：y(j, z) = x_j + o_j(z)，o 就是 δ（刚性）；
- 数据比特 q：允许的指标向量恰好是若干差分不等式 lo ≤ y(j, z) − y(j, z') ≤ hi 的整数解（"台阶"：按读时刻的循环序单调、总落差 ≤ 1）；`dc.py` 对每个数据实现核对了"不等式解集 = 枚举出的切口模式"；
- 私有读者：两项相等；翻转：多出两项 t、t+1。

**定理 6。** 在每个分支内，提升可行当且仅当约束图没有负环；S 在体内提升当且仅当某个分支可行。负环沿读者走一圈，钩子边贡献 δ 的差，数据列贡献至多其松弛，环的和乐超过松弛就是不可提升的证书。

**推论 7（两钩子证书）。** 若 S 含两个刚性钩子 f（写者 c）、g（写者 c′），以及两个对它们私有的读者 z、z′，且 δ(c, z) − δ(c′, z) ≠ δ(c, z′) − δ(c′, z′)，则 S 在体内（从而在满足窗口条件的任何 R）都不能提升。这是 G_XZ 上 4-环 c–z–c′–z′ 的和乐非零。

在 R = 1 时一个读者就够（所有写者实例都在同一轮）；在体内需要两个读者给出相反的先后，这正是图 1(b)"读出夹在两个钩子到达之间"的体内版本。

两个独立的精确求解器：`bulk.py`（带偏移的并查集 + 配对分支）与 `dc.py`（Bellman–Ford）。一个关于第一版并查集求解器的教训见第 9 节。

## 8. 为什么 u11、c11、bb18 成立

u11 的计时：X 在 1, 2, 3, 4, 5, 9 做 A2A1A3B3B2B1，Z 在（回绕后的）0, 4, 5, 6, 7, 8 做 B1B2B3A3A1A2。左比特上 Z 的 B1 读在 X 的 A 项之前，右比特上 X 的 B1 在 Z 的 A 项之后，所以所有经过 B1 的 X–Z 对在实例标号上错开一位，其余 6 对不错开：δ = −[j ≠ 1]。c11 是同一个模板交换左右块（A↔B）之后按 A1→B3、A2→B1、A3→B2、B1→A2、B2→A1、B3→A3 重新标号得到的（扭转在 A2 上）。扭转之后，任何一对出现在轻逻辑里的钩子，只要有两个私有读者一个经过扭转项、一个不经过、方向相反，就被卡住；u11 的权重 10 逻辑每一个都恰好含这样一对。

这个解释的边界也清楚：IBM depth-8 的 δ 同样是单项扭转，但它的顺序类里有不被任何非零和乐环约束的轻逻辑，所以停在 10。扭转的位置必须与顺序类的轻逻辑结构配合；这一步目前只能通过列表计算核对。

bb18 不是平移不变的电路，有 5 对 X、Z 校验支撑完全相同（共享 6 个比特），δ 在这些对上取两个值（同一对校验内部就交错），所以第 3 节的 1-余链语言不直接适用；权重 2、3 的轻逻辑被同样的差分约束卡住；那里的钩子环证书只覆盖一部分（Z 基底 w3：11/54），其余靠数据松弛。

## 9. 构造：u11 模板

`template.py` 按项给出 X、Z 的计时，对任何 A、B 各三项的 BB 码生成平移不变调度；左比特上的三个 X CNOT 在 A 项的步、三个 Z CNOT 在 B 项的步，右比特相反，所以合法性和 δ 与码无关。它在 gross 上逐字复现 u11。在 [[90]] 上，交换左右块（A↔B）并按 A1→B3、A2→B1、A3→B2、B1→A2、B2→A1、B3→A3 重新标号后，它逐字复现 c11。

[[108,8,10]]（`results/theoryB/specs/bb108_u11tpl.json`，周期 11，单辅助，回绕）：
- 评估器 `validate_schedule` 无问题；模型与 DEM 签名集合相等（R = 2，两基底 1188 = 1188）；窗口条件成立。
- 扩展码：270 列，5 个平移轨道；E-014 的 DFS（`search/experiments/e014/dfs128_all.c`，未改动）W = 7 两基底 0 解，所以 d_ext = 8；完整列表 w8 = 54、w9 = 2268（每基底，轨道展开并逐个核验）。
- 体内：w8（+1 翻转）、w9 两基底 0 提升 ⇒ 定理 5 给出任意 R、两基底 d_circ = 10。

这个电路的意义有限：E-013 已经有 [[108,8,10]] 的深度 8 分段电路达到 10，本电路周期 11，只说明"从判据出发，同一模板在另一个码上直接成立"。同一模板在 [[90]] 上失败，所以它不是对所有 BB 码的构造；对给定码要在 72 种项重标号（含 A、B 互换）里挑，判据给出了怎么挑：保留 d_ext 最大的顺序类，并让所有轻逻辑的钩子环和乐非零。[[288,12,18]] 没有尝试（扩展码列表超出本次预算）。

## 10. 局限

- 判据不是局部的：它要求列出权重 d_ext … d−1 的轻扩展逻辑。证书本身短（大多数是 2–4 条边的环），可以手核，但"列表完整"仍然是计算（这三个电路的列表都已有两套独立枚举，u11、c16 有 VeriPB 证书）。没有找到只看 (δ, 顺序类) 就能判定的不等式；IBM depth-8 说明仅凭扭转形状判断不了。
- 推广 Lemma 2 的相同列配对，我的 `small.py` 只枚举了 S 内部的列；d − d_ext ≤ 2 的情形（本文全部电路）不需要它。
- 第一版并查集求解器有一个回溯缺陷（换选项时没有恢复入口状态），会漏掉可行解；用"有限 R = 1 的提升必须包含于体内提升"这个由窗口引理保证的关系抓到（ctl_p10 432 对 424），修正后两者相等，并加了第二个独立求解器。修正前的输出保存为 `results/theoryB/gross_BUGGY_solver_v0.jsonl`，不可引用。
- 审计见 `research/audits/2026-10-29-theoryB.md`：无推翻；u11（Z）、c11（X）、bb108（两基底）从列表到提升由审计独立代码重做。新颖性见第 11 节。
- CPU：约 2.5 h，始终单进程（中途一次短暂两个进程重叠，各约 10 s）。

## 11. 新颖性核查（2026-10-30，只读检索，范围有限）

检索方式：WebFetch 读了 SBB 全文的前 2/3（HTML）和若干摘要页，WebSearch 查了"cochain / coboundary + syndrome extraction schedule"和"spacetime code / periodic DEM"。没有通读每篇全文，所以下面的判定是"在看过的部分未见"，不是"确认没有"。

| 来源 | 看了什么 | 有没有 δ 余链 / 上边缘 ⇔ 可分段 | 有没有"钩子相消 = 差分约束 / 负环" | 有没有体内 / 时间圆投影 |
|---|---|---|---|---|
| SBB，arXiv:2603.05481 | HTML 前 100k 字符：§II.1 非交错的定义（"all X-type CNOTs precede all overlapping Z-type CNOTs"）、§IV.2 Cor. 1 的证明草图（"temporally partitioned"）、§IV.3 的开放问题 | 无。只有非交错与时间分割的概念，没有"可分段 ⇔ 上边缘"或优先图的环 | 无 | 无（深度按 m 轮极限定义；§VII 把轮间重叠列为未来工作） |
| Manes–Claes，arXiv:2308.15520（Quantum 9, 1618） | 摘要与检索摘要 | 无（结论是 HGP 码对任意电路距离稳健） | 无 | 无 |
| Webster–Jacob–Higgott，arXiv:2603.22532 | 摘要 | 无（距离计算算法基准与 codeDistance 包） | 无 | 无 |
| Tan–Stambler，arXiv:2409.02193 | 摘要 | 无 | 无 | 无 |
| Shaw–Terhal，arXiv:2407.16336 / 2604.09797 | 项目已有笔记（E-017、E-019） | 无；它们用时间反演折叠（Prop. 1），对象是 morphing 电路 | 无 | 折叠到单轮，与时间圆投影不同 |
| 时空码 / DEM 文献（检索结果，如 arXiv:2508.08246 的时空码构造、Quantum 2025 的 DEM 教程） | 检索摘要 | 无 | 无 | 有限 T 轮展开的时空码是标准做法；按时间周期取模的"时间圆"在 Floquet 码文献中在精神上很可能已有（周期边界），但没有看到用它来给单辅助比特电路距离下界 |

判定：
- **δ 余链与"体内可分段 ⇔ δ 是上边缘"**：在看过的来源里未见，证据强度中等。SBB 的非交错与"时间分割"是它的特例（δ 为常数），论文必须引用 SBB。
- **提升 = 差分约束、负环证书、两钩子两读者证书**：未见，证据强度中等。图 1 的"读出夹在两个钩子之间"是它在 R = 1 的特例，这一点本项目已经写在论文里。
- **时间圆投影（N = 1 即扩展码）**：形式上简单，周期边界的时空码在 Floquet 文献中很常见，**不能声称新**；只能说"把扩展码解释为一轮时间圆"是一个表述。
- **窗口引理**：是一个关于评估器展开的技术引理，无新颖性可言。
建议若要写进论文，先让 lit-scout 通读 SBB 全文后 1/3 和 2–3 篇 DEM / 时空码综述再定措辞。
