## 记号

两轮 morphing 电路（Shaw–Terhal 2407.16336）：母码（中间码）M = BB 码 [[2N, k, d_M]]，左比特 L(g)、右比特 R(g)，g ∈ G = Z_l × Z_m；
同态 f: G → Z_2，K = ker f。收缩电路 F_0、F_1 各 3 层 CNOT。第 r 个半周期（收缩 c，上一个收缩 p = 1 − c）：

    层 0：复位右比特（基底 = 上一轮 meas[p]）；层 1..3：F_p†（gates[p] 倒序）；层 4..6：F_c；然后测量右比特（meas[c]）。

中点（层 3 之后）的态是 M 的码态；半周期起点 / 终点的左比特分别承载端点码 C~_p / C~_c（N 个比特）。
以 Z 记忆（X 型错误、旗基底 Z）为例，X 记忆完全对偶。M 的 Z 校验分成 Σ_p（在 F_p 下收缩到一个 Z 复位右比特）与 Σ_c（在 F_c 下收缩到一个 Z 测量右比特），
各 N/2 个；每个稳定子恰好在一轮收缩（E-019 逐电路推导）。

对半周期内的每个单故障 f（CSS 投影后的 X 分量）定义
- 前推到半周期末：b_f = 左比特部分（C~_c 上的数据错误），ρ_f = 落在 Z 测量右比特上的部分（本轮 N/2 个测量的翻转，称“测量旗”）；
- 后推到半周期起点：a_f = 左比特部分（C~_p 上的数据错误），r_f = 落在 Z 复位右比特上的部分（“复位旗”；落在 X 复位比特上的 X 是新鲜态的稳定子，去掉）；
- 中点像：U_f（2N 比特上的 X 串）。

## 理论（阶段 1）

### 定理 1（精确归约：morphing 扩展码）

设 S 是第 r 个（内部）半周期内的一组单故障。则
(i) S 不触发任何探测器 ⇔ Σ_{f∈S} U_f 与 M 的全部 Z 校验对易 ⇔ Σρ_f = 0 且 Σb_f ∈ ker H~_c ⇔ Σr_f = 0 且 Σa_f ∈ ker H~_p；
(ii) 此时 S 翻转逻辑量 ⇔ Σb_f 是 C~_c 的非平凡逻辑算子 ⇔ Σa_f 是 C~_p 的非平凡逻辑算子。
于是单轮电路距离 = 下面这个线性码（“morphing 扩展码”，终点视角）的最小权重逻辑：列 = 半周期内的故障，
校验行 = [H~_c b_f ; ρ_f]，逻辑行 = L~_c b_f（L~_c 为 C~_c 的另一类型逻辑算子）。起点视角 [H~_p a_f ; r_f] 与中点视角（M 的校验作用于 U_f）给出同一个码（行空间可逆变换）。
结合 Prop. 1 折叠（2604.09797；E-019 逐电路以计算核对其前提，auditor 复核），任意轮数的 d_circ 等于该扩展码的距离。

证明。
1. 每个故障在 Clifford 电路中等价于中点处的一个 Pauli U_f（层 1..3 的故障前推，层 4..6 与测量翻转后推；复位翻转前推）。
2. 中点之后，U 经 F_c 变成 (b, ρ_full)。右比特全部被测量：Z 测量比特 q 的结果翻转 ⇔ ρ(q) = 1；q 恰是某个 Σ_c 稳定子 S 的收缩像，
   所以“q 翻转”⇔ U 与 S 反对易。X 测量比特上的 X 无影响。左比特上 b 无噪声地进入下一个半周期。
3. 探测器（E-019 推导的探测器与这里的“自然探测器”张成同一空间，E-019 instance.py 断言）：Σ_c 中 S 的探测器 = m_r(S) ⊕ m_{r−1}(S 在 F_p 下扩张像的右支撑)，
   只被 m_r(S) 的翻转触发，即 [U, S] ≠ 0。Σ_p 中 S' 的探测器 = m_{r+1}(S') ⊕ m_r(R^c_{S'})，其中 F_c S' F_c† = S~'_c ⊗ R^c_{S'}：
   下一半周期中点处的错误是 φ_c(b) = F_c†(b ⊗ I)F_c，它与 S' 的对易性 = b·S~'_c；m_r(R^c_{S'}) 的翻转 = ρ·R^c_{S'}；两者之和 = [F_c U F_c†, S~'_c ⊗ R^c_{S'}] = [U, S']。
   再往后的探测器：第 t ≥ r+2 个半周期的 Σ 探测器检验的是上一半周期刚收缩过的稳定子，与“纯左比特错误的扩张像”对易，故不被触发（这正是 E-019 核对过的“局域性”）。
   所以 S 不可探测 ⇔ U 与 Σ_p ∪ Σ_c（= M 的全部 Z 校验）对易。
4. 终点视角：Σ_c 条件 ⇔ ρ = 0；在 ρ = 0 下，Σ_p 条件 ⇔ b ∈ ker H~_c（H~_c 的行 = Σ_p 扩张像的左部）。起点视角对称（Σ_p ⇔ r = 0，Σ_c ⇔ a ∈ ker H~_p）。
5. 逻辑：中点态的稳定子群 = F_p†(stab(C~_p) ⊗ 复位态)F_p = M 的稳定子群（秩 2N − k，k 相等），故 U 的 M 逻辑类、b 的 C~_c 逻辑类、a 的 C~_p 逻辑类一一对应；
   可观测量（端点码逻辑读出）翻转 ⇔ 类非平凡。∎

数值核对（`solve22.py`，阶段 0 预测 P0-1）：56 个小母码电路 × 2 基底 × 2 种半周期相位（p,c）=(0,1),(1,0)，终点与起点视角，
扩展码距离与 E-019 的 d_circ **224/224 相等**（`results/E-022-morphing-criterion/ext_*.json`，总计约 1.5 CPU min）。

### 引理 2（只有边界数据错误不会掉距离）

若 S 只含半周期起点的左比特数据错误 D_s 与终点的左比特数据错误 D_e，则 S 不可探测 ⇒ |S| ≥ d~。
证明：起点数据错误 e 的 r = 0，终点数据错误的 ρ = 0；φ_p(e) 与 Σ_p 自动对易，φ_c(e') 与 Σ_c 自动对易。
所以 Σ_c 条件只约束 D_s：Σ_{D_s} e ∈ ker H~_p；Σ_p 条件只约束 D_e：Σ_{D_e} e' ∈ ker H~_c。两者各自是码字，乘积非平凡 ⇒ 至少一个是非平凡逻辑 ⇒ |S| ≥ d~。∎
推论：d_circ ≤ d~（C~_p 的最小逻辑作为起点数据错误），且任何低于 d~ 的见证都必须含至少一个“内部”故障（CNOT 或复位 / 测量翻转）。

### 一个被否定的猜想（P0-2）

“每个故障要么 r_f = 0 要么 ρ_f = 0（单侧无旗）”——错：bb108 paper 的 1134 个故障中 702 个两侧都带旗（bb144：936/1512），
所以单侧无旗扩展码（`classify.py`，d 都 ≥ d~）不能给出下界。

## 训练集上的结构（阶段 2，80 电路中的 56 个小母码电路；[[288]] 只做了列计数）

- **钩子目录与码无关**：扩张半周期内每个故障 |a_f| ≤ 3、|r_f| ≤ 2；按（层, 左/右, 分量）分类的 (|a|,|r|) 类型表对所有码、同态完全相同，只随 std / Table VIII 变化（`classify.py` 输出）。
  典型：中点处右比特的单比特 X（层 3，“cx3R”）后推 = 3 个数据比特 + 2 个复位旗；层 2 左比特故障 = 1 个数据比特 + 1 个旗（“帽子”）。
- **最小见证的形状**：8 个掉距离电路（两基底）的 DFS 见证全部是“起点数据错误 + 扩张半周期里旗相互抵消的钩子链”，
  例：bb108 paper Z：2 个数据错误 + 2 个 cx3R 钩子（数据 {18,19,41} 旗 {10,18}、{3,40,41} 旗 {2,18}，共享旗 18）+ 2 个帽子（旗 10、2），
  4 个内部故障给出数据权重 6（41 抵消），加 2 个数据错误 = C~_p 的权重 8 逻辑；6 < 8。
  bb108 repo：同样的链但数据只能贴上一个**权重 9** 的逻辑（4 个故障贡献 6，3 个数据错误补齐）→ 7。所以只看最小权重逻辑不够。
- **消融**（`ablate.py`，16 个掉距离实例）：Z 记忆下 cx3R（X 记忆下 cx3L）是 paper/std01 掉到 6 的必要类；对其余电路许多两类组合都足够（机制冗余）。
- **只用一半半周期**：训练集上 d(扩张半周期) = d(收缩半周期) = d_circ，112/112。→ 这条在新电路上**被推翻**（见下）。

### 损失机制（训练 + 新电路合起来看，阶段 3 的普查）

1. **(A) 中点钩子**：中点两侧 CNOT 层（Fd2、F0）的双比特故障在 M 上是权重 2 的错误；它们拼出 M 的逻辑时 d_circ 可降到 d~ 以下
   （例：随机码 r2n72k4i5，d~ = 3，d_M = 4，一个 Fd1 故障 + 一个 F0 故障 = 权重 2 的不可探测逻辑）。也有 9 个新电路 d_M < d~。
2. **(B) 边界数据 + 单侧带旗钩子链**（训练集的全部 8 个掉距离电路）。
3. **(C) 跨两半的双旗簇**：两侧都带旗的故障两两抵消 r 与 ρ（11 个新电路只能这样掉，见下表“都不解释”一行）。
任何一个简化模型（只中点、只一半、只边界）都不等于 d_circ；只有完整的定理 1 扩展码是精确的。

## 结论与诚实评估

1. **定理（已证明）**：两轮 morphing 电路的 d_circ 等于“morphing 扩展码”的距离——端点码 C~_c 的校验 + 本轮 N/2 个测量旗（或对称地 C~_p + N/2 个复位旗），
   列为半周期内每个单故障的（数据错误, 旗）。所以“何时掉距离”的精确判据是：存在一组旗相互抵消的故障，其数据部分与端点码的某个非平凡逻辑（不一定是最小权重的）
   相差的权重 + 故障数 < d~。证明依赖 Prop. 1 折叠（E-019 已逐电路以计算核对，新电路 576/576 同样通过）。
   这是 Strikis 扩展码在 morphing 电路上的精确对应物，差别是：(a) 它是等式而不只是下界；(b) 需要“旗”行——morphing 没有专门辅助比特，复位 / 测量记录充当旗。
2. **已证明的推论**：d_circ ≤ d~；只有边界数据错误的组合不会掉距离（引理 2），所以掉距离必须有内部故障。
3. **不是定理、只是观察**：两基底总相等（368/368）；损失 d~ − d_circ ≤ 2（344/344 小母码电路 + wm180 的 5 个）；d_circ ≥ ⌈2d~/3⌉（同上，无反例）。
4. **被推翻的简化**：“只用扩张半周期”（训练 112/112，新电路 31 处失败）；“单侧无旗”；简单的 d~ / 变体类别规则（B2、B3）。
   没有找到比完整扩展码更便宜、又在全部电路上精确的结构判据；掉距离有至少三种机制（中点钩子、单侧带旗钩子链、跨两半的双旗簇），各自都不完备。
5. **实用价值**：判据只需两组 3 层 CNOT 与端点码，不需要探测器推导、采样或 stim；小码 < 1 s。大码（N = 90）反而比 E-019 自然基底实例慢 10–30 倍（同一个码、不同行基底），没有加速。
6. 对 PRL 的意义：可以写成“定理 + 机制 + 864 个独立实例上的预注册检验”，但应如实说它是精确的计算判据，而不是能用 d~ 或多项式直接读出的闭式条件。
