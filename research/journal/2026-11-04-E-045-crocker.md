## 一句话结论

三个问题都有了确定答案。(A) Crocker 发布的 Tesseract CZ 编译 gross 电路，两个记忆基底，投影到记忆基底探测器后没有权重 ≤ 9 的不可检测逻辑，两份 VeriPB 3.0.2 证书都通过；权重 10 的见证在**未投影**的完整电路上 stim 重放通过，所以 d_circ = 10。顺带发现，投影后的 Tesseract DEM 与我们评估器 SD6 下 IBM 深度 8 电路 R = 12 的 DEM 在一个格点映射下逐列同构（两基底），所以 CZ 编译加 SI1000 噪声在这个问题上什么都没改变。(B) 在我们 E-037 重建的 decoder_setup.py 模型（R 个有噪声周期 + 2 个无噪声周期）里，gross 两个基底对**每一个** R 都有 d_circ = 10，[[108,8,10]] 对每一个 R 都是 8。下界靠一个时间平移 + 末端条件 + 连通压缩的论证，把任意 R 的轻逻辑压进 R′ ≤ 11（gross）/ R′ ≤ 9（[[108]]），那里 E-037 已有 VeriPB 证书，不需要新证书。(C) 没有找到距离随 R 增大的回绕单辅助电路，而且对“每类校验一个时序”的平移不变电路可以证明不会发生。

## B. IBM 12+2 模型：每一个 R

我先想清楚要证明的形状。decoder_setup.py 模型有两个特点让它比 SD6 好处理：每个周期的门完全相同，而且起点没有边界效应（帧从零开始，第一周期的探测器就是原始测量值，故障发生前所有测量都是 0）。所以只剩末端这一个边界，问题归结为三步。

**平移引理（构造上成立）。** 第 c 个周期里的一个故障，后面跟的门序列与“同一故障放在第 0 周期、总周期数少 c”完全相同，所以它的列就是后者的列整体平移 c 个周期。

**末端条件 (E_T)。** 第 0 周期的每个故障，其列与总周期数 N 无关（N ≥ 1 + T）。我对这个条件做了精确检查而不是抽样：无故障的帧动力学是有限状态空间上的确定映射，对每个故障算出帧状态（全部比特）的最终周期 s_{t0+p} = s_{t0}，再要求每周期的测量记录和逻辑值 L·data 在一个周期上为常数，这就覆盖了所有 N。由此得到每个故障需要的最小 N（`ibm_allR.py premises`，`partB/premises.json`）：

| 码 | 故障类型（基底） | 最小 N 的最大值 | (E_0) | (E_1) | (E_2) | a | w |
|---|---|---|---|---|---|---|---|
| gross | X 型（Z 基底） | 3 | 否 | 否 | 是 | 1 | 1 |
| gross | Z 型（X 基底） | 2 | 否 | 是 | 是 | 1 | 1 |
| [[108]] | X 型（Z 基底） | 3 | 否 | 否 | 是 | 1 | 1 |
| [[108]] | Z 型（X 基底） | 2 | 否 | 是 | 是 | 1 | 1 |

（a = 第 0 周期故障第一个探测器所在周期的最大值，w = 每列探测器周期跨度的最大值。）帧状态的周期 p 是 1 或 2：周期 2 来自 PrepX 不清零导致 X 辅助比特上的残留 X 每周期往数据上加一次 X_c，这正是 E-037 讨论过的“不改变任何列”的效应，这里在动力学层面直接看到了它；改用清零版本周期全是 1，最小 N 不变。在 T = 2 下，我还逐个核对了 R = 1、2、5、12（[[108]] 到 10）的列集合 = 第 0 周期列的平移并集 = E-037 证书所用的 `ibm_model.build_dem` 列集合，三者相同。

**压缩。** 设 F 是 k 列的不可检测逻辑。按“探测器集合相交”连边，F 的某个连通分量 C 自身就是不可检测逻辑（每个探测器只被一个分量碰到），|C| ≤ k。C 的探测器周期区间连成一片，长度 ≤ Σ 跨度 ≤ k·w；每列取一个表示（周期 c_j，第 0 周期故障 f_j），c_j 落在 [首探测器周期 − a, 首探测器周期] 里，所以 max c − min c ≤ k·w + a。把 C 整体平移到从第 0 周期开始，由平移引理它仍是同一模型里的不可检测逻辑，翻转同样的观测量；由 (E_2) 这些列在 R′ = k·w + a + 1 的模型里也一模一样。gross k = 9 给出 R′ ≤ 11，[[108]] k = 7 给出 R′ ≤ 9。E-037 对 IBM 模型在 gross R = 1..12、[[108]] R = 1..10 的每一个 R、两基底都有 VeriPB 证书，所以：**对每一个 R ≥ 1，gross 无权重 ≤ 9、[[108]] 无权重 ≤ 7 的不可检测逻辑。** 整个论证只用到 (E_2)、平移引理和“每列至少有一个探测器”（核过：没有不触发探测器却翻转逻辑的单故障），都已计算核对。

上界：R = 1 的权重 10（gross）/ 8（[[108]]）见证由 E-037 的搜索在 E-037 DEM 上找到；它的故障都在第 0 周期，由 (E_2) 在任何 R 下列不变，所以对每一个 R 都是不可检测逻辑。stim 重放（`persist_ibm.py`，`partB/persist.jsonl`；无噪声 stim 电路，stim 自己的帧模拟，故障放在第 0、⌊R/2⌋、R−1 周期，R = 1, 2, 3, 5, 8, 12, 13, 20, 30）：四组（两码 × 两基底）全部探测器为 0、翻转的观测量与 R = 1 相同；R = 1 和 R = 30 去掉任一故障都至少触发 3 个探测器。最后一个有噪声周期的放法（R−1）正是末端条件管的那一处，它也通过。

**合起来：IBM 模型（R + 2）下，gross 两基底对每一个 R 都有 d_circ = 10，[[108,8,10]] 对每一个 R 都是 8。**

**独立旁证**（不依赖压缩论证，E-037 审计员的独立 DEM 构造 + mincc，没有 E-037 的附加约束，`partB/direct/mincc.jsonl`）：[[108]] 两基底 R = 11, 12, 13, 14, 16, 20 全部无权重 ≤ 7；gross 两基底 R = 13 都无权重 ≤ 9（X 型 3.1×10¹⁰ 节点 1,627 s，Z 型 3.9×10¹⁰ 节点 1,334 s）。这是 E-037 证书范围之外第一个 R 的直接穷举，与压缩论证一致。

**Crocker 的包含性检查**（`ibm_allR.py inclusion`，`partB/inclusion.json`）：R 模型的列集合 ⊆ R + 1 模型的列集合，R = 1..18 全部检查（含他列的 1..14、16、18）。T = 2 下两码两基底全部成立，与他一致。T = 0 全部不成立（每步缺 382 / 367 列，[[108]] 274 / 273）。T = 1 我们与他的说法**部分不同**：X 型故障（Z 基底）不成立，每步恰好缺 72 列（[[108]] 54 列），即每个 Z 校验一个，就是第 7 轮 PrepZ 之后的 X 故障——它翻转下一周期的测量，需要后面再有一个周期才能出现第二个探测器；Z 型故障（X 基底）T = 1 已经成立（最小 N = 2）。这与上表的 (E_1) 完全吻合。如果 Crocker 的“0 或 1 个尾周期都不成立”指的是 Z 基底，就没有分歧；对 X 基底我们的重建给出 T = 1 已够。值得请他核对。

## C. 有没有电路的 d_circ 随 R 增大

我先想的是什么时候**不会**增大。若 R → R + 1 时 DEM 的每一列都还在（原位包含），或者每一列推迟一个周期后都还在（推迟包含），R 轮的任何不可检测逻辑就搬得到 R + 1 轮，d_circ(R + 1) ≤ d_circ(R)。E-043 审计员证明了 (Wt) ⇒ 原位包含。对推迟包含我写了对偶的论证：在 (Wb) 下每个读者的第 −1 个实例都在时刻 0 之前读，所以有限台阶指标 = min(体内指标, R)；整体推迟 P 层后体内指标加 1，有限指标 min(体内 + 1, R + 1) 恰好也加 1，写者实例 j → j + 1 和每个半整数时刻的数据故障在 R + 1 轮里都存在，测量翻转 {t, t+1} → {t+1, t+2}，残余数据误差不变，所以列整体后移一轮、观测量不变。再看评估器的 `unroll`：σ 取使结束时间最小的那个，若所有起点都 ≥ 1，把 σ 减 1 结束时间就更小，所以最优展开里最早的起点是 0。对“每类校验一个时序”的电路（本项目的平移不变单辅助电路都是），一个基底里只有读者类和写者类两个起点：(Wt) 不成立要求写者起点晚于读者起点，于是读者起点是 0，这时读者第 0 实例的读全在 [1, P) 里，(Wb) 必然成立。**所以这类电路在每个基底至少满足 (Wb)、(Wt) 之一，d_circ 对 R 单调不增，不可能随 R 增大。** 两者都不成立只可能出现在逐校验时序不同的电路里。

计算核对：

- 窗口条件（theory B `window.py`）扫了项目里 18 个 gross/[[90]] 规格和 3 个 Kunlun 规格：不满足的只有 ctl_p10 X（只缺 Wt）、Fig. 12 Z（只缺 Wt）与 X（只缺 Wb）、p18w Z（只缺 Wt）与 X（**两者都缺**，p18w 是颜色对称族，逐校验时序不同，正好是上面论证允许的例外）。
- 在评估器 SD6 DEM 上直接比较列集合（`partC.py incl`，`partC/inclusion.jsonl`），R = 1..4 → R + 1：ctl_p10、Fig. 12、p18w 两基底，原位包含与推迟包含**全部成立**（缺 0 列），连两个条件都不满足的 p18w X 也一样。窗口条件是证明用的充分条件，实际远没到必要。
- 随机电路（`partC.py randincl bb72 300 20261104`）：[[72,12,6]] 上 300 个随机合法确定的平移不变回绕调度（任意项顺序、周期 8–12），600 个“调度 × 基底”里 Wb 且 Wt 199、只有 Wb 241、只有 Wt 160、**两者都不满足 0**，与论证一致；抽查的 40 个（每类都有）R = 1..3 的原位和推迟包含全部成立。另一个小样本精确算了最小权重：4 个调度 × 基底在 R = 1、2、3 分别是 (6, 6, 6)、(5, 5, 5)、(3, 3, 3)、(6, 6, 6)。
- ctl_p10 X（Crocker 点名的那种 (Wt) 不成立的电路）精确最小权重（mitmsearch，72 平移逐项核验）：R = 1、2、3 都是 **11**（W = 10 无解，节点 2.8×10⁸ / 2.8×10⁹ / 5.0×10⁹；W = 11 找到）。不变。
- Fig. 12 与 p18w 不是严格 72 平移不变，直接搜索器不接受；它们的 d_circ 已有对任意 R 的审计定理（11 与 12，STATE 第 3、13 条），在 R 上本来就是常数。

所以对 Crocker 的问题的回答是：我们不知道、也没找到这样的电路；对平移不变、每类一个时序的单辅助电路（含回绕）可以证明 d_circ(R) 单调不增；可能的例外只在逐校验时序不同的电路里，项目里唯一一个（p18w X）的 DEM 仍然逐轮包含，距离是常数 12。
