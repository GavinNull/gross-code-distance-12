# E-038 · Kunlun 芯片上的 [[18,4,4]] 能不能做到电路距离 4

- 日期：2026-10-26 / 执行者：experimenter / 配置与预测：`experiments/E-038-bb18-d4.yaml`（24b6bf0，任何计算之前提交）
- 代码：`search/experiments/e038/`；原始结果：`results/E-038-bb18-d4/`（不进 git）
- 评估器只读（`candidate.parse_schedule / validate_schedule / memory_circuit`、`noise.add_noise(sd6)`）；码、支撑、逻辑基、auditor 的独立故障模型从 `e036_audit/core.py` import。

## 结论先说

**能。** 芯片约束内（14 个被测校验、只用 84 个 Tanner 耦合器、每校验一个辅助比特、无旗标、每轮同一调度、不回绕）存在 **8 层 CNOT（周期 10）** 的电路 `search/experiments/e038/bb18_n8_d4_spec.json`，SD6 下任意 R、两个基底 **d_circ = 4 = d**。这比实验多一层 CNOT。

和它配套的不可能性（全部是"在 SD6 体内（R 足够大）每个电路都有权重 ≤ 3 的不可检测逻辑"，CNF + CaDiCaL DRAT + drat-trim 验证，见第 4 节）：

| 类 | 结论 |
|---|---|
| 不回绕，6 层 CNOT（N6） | 不可能（DRAT 验证；E-036 结论的第三次独立确认） |
| **不回绕，7 层 CNOT（N7，Kunlun 的深度）** | **不可能**（最终 CNF 分 42 个 cube，42/42 DRAT 验证） |
| IBM 式流水：所有 X 校验同一制备时刻、所有 Z 校验同一制备时刻 δ（V），P = 8 | 每个 δ = 0..7 都不可能（DRAT 验证） |
| 同上，P = 9 | 每个 δ = 0..8 都不可能（δ = 0 ⊂ N7；δ = 1..8 DRAT 验证） |
| 一般流水（每个校验自己的制备、测量时刻），P = 8、9 | **未决**（SAT 调用太慢，见第 5 节） |

不受芯片约束、18 个校验全测（36 比特）时 **7 层 CNOT 就够**：`full_n7_d4_spec.json`，d_circ = 4，任意 R。所以去掉 4 个冗余校验（Kunlun 芯片的做法）恰好让 7 层变得不可能，代价是多一层。

LER（E-036 的 Tab. S1 映射、同一 BP-OSD、预设 200,000 shots、R = 6）：论文噪声下我们的 8 层电路每轮差 9–11%（多一层的噪声），×0.1 时 Z 基好 13%、X 基差 15%；事后加的 ×0.02 一档（不是预注册）两个基底都明显更好（0.40、0.72）。距离 4 的好处要在比 Kunlun 好约 50 倍的器件上才显出来。

## 我怎么想的

E-036 和它的审计已经说明：非交错一律 ≤ 3（码性质），不回绕 6 层不可能。两套 CEGAR 卡在 7 层，原因很清楚：它们的 nogood 是"这组顺序字面量全部保持"，每条只排除一个很小的胞，7 层的胞太多。

我的判断是：SD6 下单辅助电路的 d_circ 只取决于事件的相对次序（每个校验内 6 个 CNOT 的次序；每个数据比特上不同校验的 CNOT 的次序；回绕时还要带上"差几轮"）。所以我把调度写成每个事件第 0 轮实例的绝对时间 τ，实例 j 在 τ + jP，直接在**体内**（无限轮）讨论：一组故障的探测器效果相消、残余数据错误是非平凡逻辑，就叫体内见证；它放进任何足够长的 memory 电路中间都成立。单个故障只有三类：数据切口（在某个读者实例之前的数据错误）、辅助比特钩子（后缀扩散）、读者测量翻转；每个效果都是"读者 f 在钩子/切口之后第几个实例第一次看到它"的函数，即字面量 LT(g, f, k) := τ_g < τ_f + kP 的函数（`model.py`）。

关键的改动是 nogood 的抽象层次。见证抽象成**模式**：哪类故障、哪个校验、哪个后缀集合、哪个数据比特、相对哪一轮；数据切口具体切在哪里不进模式（攻击者可以随便挑切口），相消条件写成每个探测器上的奇偶约束（Tseitin XOR）。一个模式排除"这组故障在其中能相消"的**所有**调度，而不只是字面量相同的调度。模式总数是有限的、不大（N7 最终 12,145 个），所以 CEGAR 必然收敛。

这样一来 N6 从审计的 97 s / 638 个 nogood 变成 20 s；N8 在 347 轮就**找到**了距离 4 的电路，这是本实验最重要的结果。

## 1. 模型的验证（`validate_model.py`、`legal_complete.py`、`validate_patterns.py`）

- 体内机制集合 vs stim：N7、W8、W9、W10 各 30 个随机合法调度（W 是逐校验制备时刻的流水），两个基底，R = 8：把我的体内机制中探测器全部落在第 2..R−2 轮的那部分，与 stim DEM（我自己的周期电路）中同一范围的机制逐个比较 (探测器集合, 观测量)，**240 组全部集合相等**；CNF 的每个模型都通过 python `legal()` 和评估器 `validate_schedule`（独立的确定性检查），stim 建 DEM 也没有报非确定探测器。
- 最小权重（≤ 3）：体内 = 我的 stim（R = 8）= 评估器模板（R = 8）在 239/240 格相同；唯一不同的一格（W8，Z 基）是我的 stim 电路的边界见证（2 < 体内 3，评估器 3），符合"有限 R ≤ 体内"。
- 合法性 CNF 的完备性（UNSAT 结论需要它）：Kunlun（N7）、E-036 的 P8 电路（N6）、我们的 N8、IBM P8 流水序（W8 与 V8 δ = 7），以及 24 个**不经 CNF**、由模拟退火修复到 `legal()` 且评估器 `validate_schedule` 无异议的随机流水调度（P = 8、9、10），归一化后全部被 CNF 接受，解码回来逐值相同。
- 模式子句的可靠性：从 N7、W8、W9 的模式里随机抽 468 条子句，让 SAT 找一个**违反**该子句的合法调度（即那组故障在其中相消），再离开 CNF 独立检查：(a) 用 `Bulk` 重建这些机制，确实相消且观测量非零；(b) 把它们平移到 R = 10 的 stim 电路中间，每个机制的（探测器集合, 观测量）都是 stim DEM 里的机制，异或为（空, 非零）；(c) 评估器模板 R = 6 的精确最小权重 ≤ 模式大小。**468/468 通过，0 例失败**（另有 N6 的 59 条）。

## 2. 找到的电路：`bb18_n8_d4_spec.json`（N8：周期 10，8 层 CNOT，不回绕）

- 全部 84 个 CNOT 都在被测校验的 Tanner 边上（按支撑识别），评估器 `validate_schedule` 无问题。
- 精确 d_circ（`certify.py`）：R = 1..5（评估器另到 6），两个基底，三套故障模型都**没有权重 ≤ 3 的不可检测逻辑**：评估器模板 + SD6；我自己的周期 stim 电路；auditor 的独立 `e036_audit.core`（符号模型 Sym 与它自己的 stim 电路，**复位与不复位**辅助比特都算）。体内模型（W = 12）也没有。
- 任意 R：不回绕电路里权重 w 的逻辑最多在 w 轮里有故障，无故障轮可删（E-036 审计的论证），所以 R = 1..3 决定所有 R。
- 上界：评估器 R = 1、2 精确找到权重 4；显式注入（`inject4.py`）在数据复位后对 {L0, L1, L6, R0} 加 X（Z），R = 1..6 都是 0 个探测器、观测量翻转。⇒ **任意 R、两基底 d_circ = 4**。
- 结构：每个数据比特上 X、Z 类 CNOT 高度穿插（例如 L1 上是 Z X Z X Z），这正是突破非交错上限 3 的方式。

## 3. 18 个校验全测：`full_n7_d4_spec.json`

不受芯片约束（36 比特、108 个耦合器）时，N7（7 层 CNOT、周期 9）的 cube 搜索在第 534 个 cube 找到 d_circ = 4 的电路，同样三套模型 R = 1..4 全无权重 ≤ 3、R = 1、2 精确权重 4。18 校验 N6 连合法电路都没有（E-036）。所以全测版在 Kunlun 的深度上就能保距离；芯片约束版要 8 层。

## 4. 不可能性证明与证书

所有 UNSAT 的 CNF = 合法性编码（`enc.py`，阶梯编码的整数时间 + 确定性奇偶）+ 全部模式子句；求解器 CaDiCaL 3.0.1（tools/cadical），证明 DRAT，由 drat-trim（tools/drat-trim）检查。

| 类 | CNF | 结果 |
|---|---|---|
| N6 | `cegar_bb18_N6_d4.cnf`（1,829 个模式） | UNSAT，**s VERIFIED** |
| V8 δ = 1..7 | `cegar_bb18_V8_d4_delta*.cnf` | 7/7 UNSAT，**s VERIFIED** |
| V9 δ = 1..8 | `cegar_bb18_V9_d4_delta*.cnf` | 8/8 UNSAT，**s VERIFIED** |
| N7 | `final_N7.cnf`（23,848 变量、125,291 子句、12,145 个模式；sha256 d8c1b023…） | 42 个 cube（X0 的 A1、A2 两个 CNOT 的层号，所有 7·6 种）**42/42 UNSAT、s VERIFIED**（`final_N7_cube_drat_d2_*.jsonl`，每个证明的 sha256 已记录，共 2.3 CPU h）；`cube_cover.py` 核对 42 个 cube 恰好覆盖全部取值、CNF 的合法性前缀与编码器逐行相同 |

N7 的路线：全局 CEGAR 的 SAT 调用涨到每次 150–900 s，我改成 cube-and-conquer：按第一个校验 X0 的 6 个 CNOT 的层号分成 7·6·5·4·3·2 = 5040 个 cube（合法性保证每个调度恰好落在一个 cube 里），每个 cube 里跑同一个 CEGAR（模式全局共享），3 个分片共 4.7 CPU h，**5040 个 cube 全部 UNSAT**，过程中模式只从 11,838 增加到 12,145（绝大多数 cube 一次 SAT 调用就 UNSAT）。增加子句不会让 UNSAT 的 cube 变 SAT，所以用全部模式的并集建最终 CNF。整体直接交给 CaDiCaL 跑了 1 h 45 min 没有结束（证明文件已到 3 GB），我停掉它，改为 42 个较粗的 cube 分别出 DRAT；合法性保证每个模型的 (τ(X0,A1), τ(X0,A2)) 是一对不同的层号，所以 42 个 cube 全 UNSAT 就是整体 UNSAT。V8、V9 的 CNF 足够小，直接整体 DRAT。另从最终并集里再抽 146 条子句做第 1 节的 stim 检查，0 例失败（模式子句抽检合计 673 条）。

## 5. 未决：一般流水 P = 8、9

逐校验制备时刻的流水类 W8、W9 比 V 类大得多（每个校验的制备时刻独立）。全局 CEGAR 到 108 轮、约 9,700 / 11,700 个模式时，每次 SAT 调用 400–900 s 仍是 SAT（每次给出的调度都有权重 2 或 3 的体内见证），按 X0 次序分 cube 的 W8 第一个 cube 跑了 25 分钟没有结论；用 V8 全部模式加 W8 已有模式重启的增量 CEGAR，第一次 SAT 调用 80 分钟没有返回，我按 PID 停掉。
所以 P = 8、9 的逐校验流水是否能到 4 没有结论。已知的是：它们包含的两个自然子类（不回绕 N6/N7、IBM 式两组制备时刻 V8/V9）都不可能；P = 10 时不回绕就够了（N8 ⊂ W10）。
如果要继续，我会先换掉"一次性整体 CNF"的做法，改成按若干校验的制备时刻分 cube（每个校验 P 种），并用那个 4 阶自同构群做对称性剪枝。

## 6. LER（`ler.py` = E-036 的 `run_one`，`analyze_ler.py`）

噪声：E-036 的 Tab. S1 → CNOT 模板映射（CX 后 DEPOLARIZE2 9.8e-3，空闲 3.5e-3/层，单比特层 8e-4，校验测量翻转 4.03e-2，测量期间其他比特 DD 通道，数据读出 3.29e-2），BP-OSD（min-sum、100 次迭代、OSD-CS 7），每点 200,000 shots，R = 6，种子 20261026，两个电路都重新采样。每轮块错误率 ε 用 E-036 的饱和修正；比值区间由两个 Jeffreys 区间保守合成。

| scale | 基 | Kunlun ε/轮 | N8（d_circ = 4）ε/轮 | 比值 N8/Kunlun |
|---|---|---|---|---|
| 1 | Z | 0.240 | 0.261 | 1.09 [1.08, 1.10] |
| 1 | X | 0.265 | 0.294 | 1.11 [1.10, 1.12] |
| 0.1 | Z | 4.15e-3 | 3.62e-3 | 0.87 [0.82, 0.92] |
| 0.1 | X | 3.81e-3 | 4.39e-3 | 1.15 [1.09, 1.22] |
| 0.02（事后，非预注册） | Z | 3.6e-4（429/200k） | 1.4e-4（170/200k） | ≈ 0.40 |
| 0.02（事后，非预注册） | X | 2.4e-4（293/200k） | 1.8e-4（212/200k） | ≈ 0.72 |

Kunlun 的数字与 E-036 一致（0.240、0.263、4.2e-3、3.9e-3）。论文噪声下多一层 CNOT 的代价压过距离；×0.1 时两个基底方向相反；距离 4 的收益要到 ×0.02 才清楚。所以对现在的器件，Kunlun 的 7 层电路（以及 E-036 的 6 层 d = 3 电路）在 LER 上仍然更好；我们的 8 层电路的价值是"芯片上可以保距离"这件事本身，以及更好器件上的标度。

## 局限

- 不可能性是体内结论："R 足够大时每个电路都有权重 ≤ 3 的见证"。模式子句的可靠性靠体内模型的推导 + 240 组机制集合与 stim 相等 + 468 条子句的 stim 抽检；合法性 CNF 的完备性靠 28 个独立调度的抽检，不是形式证明。
- 对称性没有用来剪枝（9 个平移都不保持被测校验集合；保持它的自同构群只有 4 阶，我没有用）。
- LER 的噪声映射是 E-036 的近似（无泄漏）。×0.02 一档是看到 ×0.1 结果之后加的。
- N8 电路的新颖性没有查。

## CPU

约 25 CPU h（预算 40）：模型/合法性/模式验证约 1.2；第一批全局 CEGAR（N6–N8、W8、W9，增量与外部求解器两种）约 9；N7 cube 4.7；全测 N7 1.4；V8/V9 1.0；DRAT（N6、V8、V9 与 N7 的 42 个 cube）约 3.2；停掉的 N7 整体求解 1.75 与 W8 重启 1.4；LER 0.9；其余约 0.5。同时最多 5 个工作进程。
过程失误：杀 W8x 的 python 时没有连带它的 CaDiCaL 子进程，那个子进程又跑完了一次调用才退出（几分钟）；外部求解器每次都写 DRAT，SAT 调用留下 1–3 GB 的无用证明文件，已删除（只删我自己生成的、未完成的证明）。
