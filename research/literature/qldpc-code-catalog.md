# qLDPC 码目录：bivariate bicycle 码及 2023 年后的推广族、评价指标、距离计算工具
检索日期：2026-10-02；检索词：bivariate bicycle codes, coprime BB, two-block group algebra codes, multivariate bicycle, BB code cover graphs, weight-6 thickness-2 qLDPC, kd^2/n, QDistRnd, BP-OSD distance estimation。
方法：论文全文下载后用 pdftotext 读表。凡写了 (l,m,A,B) 的码，我另外用脚本在 GF(2) 上按 H_X=[A|B]、H_Z=[B^T|A^T] 重建校验矩阵并算了 k = n − rank(H_X) − rank(H_Z)，**k 全部与论文一致**（这只验证了多项式没抄错和 k，**没有验证距离 d**）。
“n” 一律指**数据比特数**；总比特数 = 2n（BB 码每个数据比特配一个校验比特，2308.07915 第 1 节表 1 注）。

## 结论（先看这里）
1. IBM 论文（arXiv 2308.07915）表 3 给出 8 个 BB 码，表 1 里 5 个带电路级数据；[[144,12,12]]（gross）、[[288,12,18]]（two-gross）是后续工作的主角。多项式在下面第 1 节逐个列出。
2. 2023 年后的推广有：coprime BB（2408.10001）、2BGA（2306.16400 / 2305.06890）、multivariate/trivariate bicycle（2406.19151）、BB 覆盖图序列（2511.13560）、BB 码的存在性与特征（2502.17052）。**同为权重 6 的新码里，没有找到在 kd²/n 上明显超过 [[360,12,≤24]]、[[756,16,≤34]]（这两个本身还是距离上界）的有据数字。**权重 8 的码更好：[[144,14,14]]（kd²/n=19.1）。
3. 最常用的比较指标是 kd²/n（相对表面码的 1，因为旋转表面码 n=d²、k=1 时 kd²/n=1）；它是 Bravyi–Poulin–Terhal 型的 k·d² = O(n) 界在二维局域码上的自然归一化，**BB 码有长程边，不受该界约束**，所以能远大于 1。必须同时报告是否把校验比特计入 n。
4. 距离计算：精确用混合整数规划（gross 论文引 Landahl–Anderson–Rice，arXiv 1108.5738），上界用 BP-OSD 随机试探（2308.07915 第 6 节式 (11)）或 QDistRnd（GAP，arXiv 2308.15140，基于 Dumer–Kovalev–Pryadko arXiv 1605.02410 的信息集算法）。电路级距离用 stim 的 `shortest_graphlike_error` / `search_for_undetectable_logical_errors`（启发式）或整数规划。
5. 不同论文对同一个码的多项式写法不同（循环移位/互换 x、y 后等价），比较时先用 (n,k,d) 对齐，不要只看多项式文本。

## 约定（Bravyi 等，2308.07915 第 3 节式 (1)(2)）
x = S_ℓ ⊗ I_m，y = I_ℓ ⊗ S_m（S 为循环移位矩阵），x^ℓ = y^m = I，xy = yx。A = A1+A2+A3，B = B1+B2+B3，每个 Ai、Bj 都是 x 或 y 的幂，各项互异。码 QC(A,B)：n = 2ℓm，H_X = [A|B]，H_Z = [B^T|A^T]，权重 6 校验，Tanner 图度 6、厚度 ≤ 2（该文引理 2）。

### 2.2 两块群代数码 2BGA（Lin & Pryadko，arXiv 2306.16400；先导文 Wang–Lin–Pryadko，arXiv 2305.06890）

## 新颖性判断
这是目录，不是新结果。与后续“码搜索”阶段相关的三点：
1. 有人对 BB 码做过系统搜索吗？有：Bravyi 等（表 3）、Wang–Mueller（算法 1/2）、Symons 等（覆盖图 + 权重 8）、Postema–Kokkelmans、Eberhardt–Steffan。搜索靠“多项式 + 距离上界估计 + 整数规划确认”，这套流程已有成熟做法，**任何“AI 搜索发现更好的 BB 码”必须对照这些结果表（尤其是 kd²/n 的已知最好值）**。
2. 在同样 (ℓ, m) 取值和权重 6 的约束下，我没有找到明确声称“穷尽”的结果；Wang–Mueller 明说大 ℓ、m 时“results are not exhaustive”（第 3.3 节）。所以空间并未被穷尽，但小规模（n ≲ 150）已经被多篇文章反复搜过，机会更可能在较大 n 或非阿贝尔群 / 非 BB 结构上。
3. 电路级（综合征提取调度）层面的工作：Shaw & Terhal（“morphing circuits”，Phys. Rev. Lett. 134, 090602，arXiv 号**未核实**，在 2408.10001 的参考文献列表里出现）。该方向是否有人做过“AI 搜索调度”：**本笔记没有查，不能下结论**，需要另派 lit-scout 做专项。

## 对本项目的建议
1. `evaluators/` 里的 BB 码表直接使用本笔记第 1 节的多项式；加载后断言 k 和 H_X H_Z^T = 0，并对前五个码断言距离（可用 stim 的 shortest_graphlike_error 在电路层面做交叉，或整数规划做码层面）。k 已核对过（脚本在草稿区，未入库）。
2. 比较码好坏时，报告同时包含：n、k、d（精确/上界标注）、权重、含/不含校验比特的 kd²/n、d_circ（指明电路与噪声模型）。拒绝只用 kd²/n 声称“更好”，因为权重 8 或不同布局会改变解释。
3. 码搜索阶段的 baseline 应包含：随机搜索 + 模拟退火在 (ℓ,m) 与多项式空间上的结果，并复现 Wang–Mueller 表 1 / 表 2 与 Bravyi 表 3 的已知码（作为搜索算法的“找回已知最好”测试）。
4. 距离估计：搜索内循环用 BP-OSD 上界（便宜）；入选候选才用整数规划确认（贵）；二者要在日志里分别标注。
