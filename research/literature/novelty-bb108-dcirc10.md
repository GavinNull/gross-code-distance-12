## 结论（3-5 行）
- **结果层面：新。** 在检查过的全部论文中，[[108,8,10]] 的电路级距离只出现过 **≤ 8** 这一个数（IBM 原电路及其改造版），出处有 4 篇：2308.07915 Table 1、2407.16336 Table I、2509.00850 Table I、2606.25330 Table I。**没有任何一篇报告 ≥ 9 或 = 10 的电路**，单辅助比特、多辅助比特、flag、morphing、交错、搜索、手工构造都没有。2603.05481（v1、v2）全文没有出现 [[108,8,10]]。证据强度：**中等偏高**（下面说明为什么不能说“高”）。
- **方法层面：已有思路的直接延伸，有一个新的具体要素。** “单辅助比特电路中，按位置（子格/颜色）给不同校验不同的 CNOT 顺序，避开与逻辑算符对齐的钩子错误”早有先例：表面码 Litinski–von Oppen 2018 的逐块 N/Z 分配、颜色码 Kishony–Fowler 2603.28852 的“按颜色区分调度”，以及 qLDPC 上 Strikis 等 2603.05481 App. H 对 gross 码的三色平铺 LRC。我们的电路就是 Strikis LRC 框架里的一个**非均匀两色平铺**。新的要素有三条：着色方式（按 y 的奇偶，而不是 Strikis 的三色）；它在 [[108,8,10]] 上恰好把 d_circ 恢复到码距离；以及项目 E-010 的负面结果（该码所有三色 LRC 的 d_ext ≤ 9）。
- **证明层面：对 BB 码是新的；对 qLDPC 码整体不是第一个。** 有严格 d_circ 证明的已有工作：HGP 码对任意顺序的解析证明（Manes–Claes 2308.15520 Thm. 2）；高维 HGP 与降权码的存在性证明（Tan–Stambler 2409.02193，只读了摘要）；放大码的严格下界证书（2609.37231）；小型 layer code 的整数规划精确认证（2609.39522）。BB 码方面，所有文献里的 d_circ 都是上界，Strikis 的 11 是猜想；IBM Tour de gross 用整数规划精确算出的只是**现象学**距离，d_circ 仍是上界（2506.03094 Table 4）。**对 d ≥ 10 的 BB 码，没有找到任何严格证明 d_circ = d（或任何非平凡 d_circ 下界）的先例**。
- **推广空白：大部分仍空。** m 为偶数的 BB 码里，[[72,12,6]] 和 [[288,12,18]] 用 IBM 原电路时上界就已等于 d，但都没有证明；gross [[144,12,12]] 最好的是 Strikis 猜想的 11，非交错电路可证 ≤ 11；[[120,8,12]]（ℓ,m=10,6）最好 ≤ 10；[[360,12,≤24]]、[[756,16,≤34]] 没有 d_circ 数字。对它们“用两色/多色 LRC 恢复距离并给出证明”的工作，**未找到**。

### 1.2 为什么证据强度是“中等偏高”，不是“高”
- 负面证据来自：作者点名的 13 篇全部读了全文；2603.05481 的全部 12 篇 S2 引用；arXiv API 摘要检索得到的 2025 年后条目；2308.07915 的 860 条引用（不完整，被限流截断）里按标题筛出的部分；Google Scholar 两次检索。**没有做 arXiv 全文检索**（arXiv 不提供），对 2308.07915 的引用也没有完全覆盖。
- 2603.05481 公开了代码库（Sec. I：“A Python codebase … is publicly available on GitHub”，Fig. 2 题注同）。理论上别人很容易把它用到 [[108]] 上，所以存在**未发表或正在发表**的抢发风险，文献检索查不到这部分。
- 2603.22532 的 BB 电路基准里，精确算法完成了一个电路，但正文没写是哪个码。从规模看，它不太可能是改进后的 [[108]] 电路（电路来自 tesseract 测试集，应当是 IBM 式电路），但我没有核对测试集。

## 2. 方法层面：“按位置改变 CNOT 顺序以避开钩子对齐”的已有工作

**判断**：
- “不同位置用不同顺序”本身**不是新思路**，必须归功于上表的已有工作，尤其是 Strikis 的非均匀（三色）平铺 LRC 和 Kishony–Fowler 的按颜色调度。
- 新的具体要素：(i) 用 **y 奇偶的两色**平铺。项目 E-011 的推理是：三色只看 x，而权重 8 见证的矩形在 y 方向跨 3（奇数），按 y 奇偶着色就能把它拆开。这个着色和这条推理在文献中**未找到**。(ii) 项目 E-010 的负面结果“[[108,8,10]] 的所有三色 LRC 的 d_ext ≤ 9”，文献中**未找到**，相当于 Strikis Prop. 6 在另一个码上的对应物，且结论相反（gross 码三色有幸存者，[[108]] 没有）。(iii) 一条可以一句话说清的规则（某侧在某种奇偶的行上反转 A 块顺序），深度和 IBM 电路相同（周期 8，2308.07915 的深度-7 CNOT 加 init/meas）。

**判断**：
- **对 BB 码（以及一般的 lifted product / 2BGA 码），d ≥ 10 时，没有找到任何严格的 d_circ 下界或 d_circ = d 的证明。** 已有 BB 码的 d_circ 全部是上界；最接近“证明”的 Strikis 也只证明了上界，11 是猜想；IBM 只精确算了现象学距离。
- 我们的证明路线是 Strikis Prop. 3（任意单辅助比特 SEC 有 d_circ ≥ d_ext(E)），加上对扩展码的完整穷举证明 d_ext(E) ≥ 10，再加上 d_circ ≤ d。这条路线 **Strikis 原文自己提出过**（Sec. IV：“potentially allowing the exact distance … to be determined using exhaustive numerical methods”），但没有执行。所以：“用扩展码化简来精确确定电路距离”这个**想法**归功于 Strikis；“对一个 d = 10 的 BB 码真正完成证明”是新的。
- 不能说“第一个严格的 qLDPC 电路距离证明”：HGP（2308.15520）、layer code（2609.39522）和放大码下界（2609.37231）都有先例。
- 2609.37231（2026-09-29）提供了另一套严格下界工具，公开时可以作为互补方法引用。

## 新颖性判断
- **有没有人做过完全相同的事？** 没有找到。没有任何论文给出 [[108,8,10]] 的 d_circ ≥ 9 的电路，也没有任何论文对任何 d ≥ 10 的 BB 码给出 d_circ 的严格下界。
- **最接近的三篇及差别**：
  1. **Strikis–Browne–Beverland 2603.05481**：框架、下界定理、非均匀平铺思路都来自这里。差别：他们只做了 gross 码（三色，猜想 11，未证明），没做 [[108]]，没有完成任何精确下界计算。
  2. **Kishony–Fowler 2603.28852**：按颜色区分的单辅助比特调度、均匀调度不可行的论证，与我们的方法逻辑同构。差别：对象是颜色码；结论靠几何分析加数值验证，边界处 d_circ < d。
  3. **Shaw–Terhal 2407.16336**：唯一为 [[108,8,10]] 换电路范式的工作。差别：结果是另一个码 [[54,8,8]]，d̃_circ ≤ 7，没有改进 [[108]] 本身。
- **证据强度**：结果层面中等偏高（作者点名的论文和 Strikis 的引用全部读了全文，覆盖完整；主要缺口是 2308.07915 引用不完整、没有 arXiv 全文检索、以及未发表的工作）。证明层面中等（“BB 码无严格 d_circ 证明”的结论依赖同样的检索覆盖；2603.22532 里有一个未注明码名的精确结果）。

## 对本项目的建议（公开表述）
**可以说是新的**（建议都加“to our knowledge”）：
1. [[108,8,10]] BB 码（2308.07915 Table 3）的第一个 d_circ = 10（= 码距离）的综合征提取电路，深度与 IBM 电路相同，每个校验一个辅助比特，所有校验每轮都测；此前文献最好是 ≤ 8（2308.07915 Table 1，2407.16336 Table I，2509.00850 Table I，2606.25330 Table I）。
2. d_circ = 10 是**定理**，不是上界：据我们所知，这是 d ≥ 10 的 BB 码第一个严格证明的电路距离（包括第一个非平凡的 d_circ 下界）。
3. 一个简单规则：按校验所在行 y 的奇偶，在一个块内反转 CNOT 顺序（两色非均匀平铺）。以及负面结果：该码的所有均匀和三色（按 x）LRC 都只能到 d_ext ≤ 9（E-010；正式写之前请确认 E-010 的穷举范围与 Strikis Prop. 5/6 的定义一致）。

**必须归功于已有工作**：
- 码：Bravyi 等 2308.07915。
- LRC 结构、残余错误、扩展码、Prop. 3 下界、Cor. 1、“用穷举精确确定距离”的想法、非均匀（三色）平铺电路：Strikis–Browne–Beverland 2603.05481。要明说我们的电路是他们框架里的一个实例。
- 按位置/颜色区分 CNOT 顺序以避开恶性钩子：Tomita–Svore 1404.3747（按类型），Litinski–von Oppen 1709.02318（逐块 N/Z），Kishony–Fowler 2603.28852（按颜色，且论证均匀调度不可行）。
- 其他严格电路距离结果：Manes–Claes 2308.15520（HGP），Tan–Stambler 2409.02193，2609.37231（下界证书），2609.39522（整数规划认证）。这些都要写明，避免被读成“第一个严格的 qLDPC 电路距离证明”。
- 相关但不同的 [[108]] 工作：Shaw–Terhal 2407.16336（morphing 后得到 [[54,8,8]]）。

**措辞上要注意**：
- 写清证明的适用范围（审计 F3）：独立的单操作故障、CNOT 门集、memory 实验边界；不覆盖关联噪声、泄漏和 CZ 编译。Strikis Prop. 3 的 SEC 模型是 CNOT 单辅助比特（Sec. II.A），与之一致。
- 不要说 gross 码问题已经解决；Strikis 的 Prop. 4 说明 gross 码的非交错电路不可能到 12。
- 引用其他码的数字时一律写“≤”。

**推广前**：先确认 [[120,8,12]]（m = 6）、[[288,12,18]]（m = 12）和 gross 码这些都是空白。gross 码上把 Strikis 的猜想 11 证明出来，是成本最低、最容易被认可的下一步。2609.37231 的证书方法可以作为独立的交叉验证。由于 Strikis 的代码已经公开，抢发风险真实存在，建议尽快公开。
