## 1. 范例的结构骨架

### 1.1 Shaw & Terhal, arXiv:2407.16336（PRL 134, 090602 (2025)）：最接近的 PRL 范例

- **摘要**：4 句。背景（BB 码性能好、码率高）→ 贡献（把 morphing 电路推广到 BB 码，连接度从 6 降到 5）
  → 次要贡献（与 surface code 做逻辑 I/O）→ 通用框架（给出 2BGA 码可用的充分条件）。没有罗列数字。
- **正文顺序**：Introduction（6 段：QEC 与 surface code → BB 码与连接度难题 → **第 3 段就给出主结果**
  → 与已有 morphing 工作的关系 → 贡献清单 → 逻辑 I/O 的新意）→ Mid-/end-cycle codes（定义）→
  QEC through morphing circuits（核心构造）→ Weight-6 Abelian 2BGA codes → Applying the morphing protocol
  （**Criterion 1 作为中心结果单独陈述**）→ The end-cycle codes → Circuit-level performance → Logical operations
  → Modifications → Outlook。
- **关键思想怎么传达**：**Fig. 1 是概念示意图**（mid-cycle 码、两个 end-cycle 码、收缩电路 F_i 的交替循环），
  没有任何数据。Table 2 给出电路定义，Fig. 2 用一个稳定子演示收缩过程。数值结果只有 Fig. 3 一张。
- **正文与附录分工**：正文给判据（Criterion 1）、电路表、一张性能图；附录 A–G 放全部证明
  （Prop. B.1、D.1–D.6）、一般 2BGA 推广、双平面性证明、逻辑 I/O 细节、电路变体，篇幅远超正文。
- **先前工作**：放在引言第 4 段，用一两句交代与 morphing surface/color code 和 "morphing quantum codes" 的区别。
- **局限与开放问题**：Outlook 一段，两三个具体方向（不满足 Criterion 1 的码、HGP 码、更高维）。
  电路距离只给上界（Table 1 标 "≤"），不回避。
- **不放进论文的东西**：搜索过程、失败尝试的时间线、内部代码名、文件路径。代码可得性一句话（"All numerical
  code is available on GitHub"）。

### 1.2 Bravyi et al., arXiv:2308.07915（gross code，Nature 627, 778 (2024)）

- **摘要**：第一句就给出头条（阈值 0.8%，288 物理比特保护 12 逻辑比特近百万轮，对比 surface code 约 3000）。
- **顺序**：Introduction → 选码判据（5 条：距离、码率、深度、厚度、逻辑操作，同时定义 circuit-level distance）
  → **Main results（Table 1 + Fig. 2 对比 surface code）** → 码的定义与引理 → 综合征电路（Table 5 伪代码 +
  Fig. 5 时序图 + 正确性证明）→ 译码器 → 数值细节 → 逻辑存储 → Conclusion。
- **关键思想**：**Fig. 1 是概念图**（surface code Tanner 图 vs BB 码在环面上的 Tanner 图，以及两层平面分解）。
- **电路距离**：在判据一节定义，在 Table 1 中一律写成上界（d_circ ≤ 10），计算方法放到译码器一节，
  并有脚注说明上界"可能不紧"。
- **启示**：结果先行；判据/定义先于构造；电路规格用"表 + 时序图"双重呈现；严格区分证明与数值上界。

### 1.3 Strikis, Browne & Beverland, arXiv:2603.05481（我们回答的开放问题出自这里）

- **顺序**：I. Motivation and summary of results → II. Preliminaries（SEC、深度界、噪声模型；**d_circ 在 II.3 正式定义**）
  → III. Left–right circuits → IV. Residual errors and circuit distance bounds（IV.1 残差，IV.2 界，IV.3 gross code）
  → V. 设计框架 → VI. 应用与比较 → VII. Discussion → 附录 A–H（H 专讲 gross code 电路）。
- **结果呈现方式**：引言的 summary 直接给出结论（证明非交错 SEC 达不到 12，给出一个"猜想"达到 11 的显式电路）。
  每个结论都有明确的地位标签：Definition 1（残差距离）、Definition 2（扩展码）、**Proposition 3**
  （d_circ ≥ d_ext，陈述后立即证明，Table I 在证明里列出各类故障如何传播到数据比特）、Corollary 1、
  **Proposition 4**（gross 的非交错上界 11）、**猜想**单独标明。
- **开放问题的原文**（Sec. IV.3，Prop. 4 证明之后）："It therefore remains an open question whether any
  interleaved circuit can achieve circuit distance 12."（引用不超过 15 词，下同）
- **可得性**：GitHub 代码库 + Zenodo DOI 存放精确电路。
- **对我们的启示**：我们回答的是它的 Prop. 4 留下的空隙，我们的论文最自然的语言就是它的语言：
  "Prop. 3 对任何电路成立；Cor. 1（d_circ ≤ d_ext）需要非交错；交错把两者解耦"。草稿没有用这条主线来讲。

### 1.4 Chao & Reichardt, arXiv:1705.02329（PRL 121, 050502 (2018)）：构造 + 小规模可核验论证

- **摘要**：两段共 6 句，问题 → 方法（flags）→ 适用范围 → 两个具体数字（7 比特测 [[5,1,3]]，17 比特护 7 个逻辑比特）。
- **Fig. 1**：资源卡通（逻辑比特 → 码比特 + 2 个辅助比特），一眼看懂主张。
- **Fig. 2 就是关键思想**：一个 [[5,1,3]] 稳定子的抽取电路，(b) 不容错版本，(c) 加 flag 的版本，
  (d) 触发 flag 的单故障导致的数据错误表。读者看一个例子就懂整篇文章。
- **一般情形**：用 "Claim 1" + 两段话的证明；对无法手证的情形直接说 "We have verified this property for ..."
  （计算机核验），不展开搜索过程。
- **数值模拟**放在最后一节，作为"实用性的感觉"，不是主结论；源码在脚注给 GitHub。
- **启示**：主张 → 最小可懂例子（图）→ 一般陈述（Claim）→ 证明或"已核验" → 次要数值。

### 1.5 Manes & Claes, arXiv:2308.15520（Quantum 9, 1618 (2025)）：回答"距离是否保持"的定理型论文

- 引言 → 预备（HGP 构造）→ 逻辑算符刻画（Theorem 1）→ **Effective code distance（Theorem 2：任意测量顺序都保持距离 d）**。
- **直觉解释紧挨在定理前**，形式证明紧随其后留在正文；Fig. 3 画出辅助比特错误如何传播。
- 局限写得很具体：为什么证明不能推广到 lifted-product/GB 码，并给出反例类型。

### 1.6 补充参照：计算机辅助的电路距离结论如何写

- **Kishony & Fowler, arXiv:2603.28852**（color code off-the-hook，非 letter）：Fig. 1 同时是直觉图与电路规格
  （哪些 hook 对哪种颜色的 plaquette 是恶性的，以及避开它们的调度）。距离公式先推导，再说明"用 Stim 验证到 d = 13"，
  地位写得清楚（数值验证，不是证明）。代码与电路给 GitHub 链接。
- **Liang et al., arXiv:2609.37231**（amplified qLDPC，非 letter）：把计算机算出的量定义成"证书"（Definition 1、2），
  Theorem 3 说明证书如何组合成 d_circ 下界；正文给证明梗概，附录给完整证明；证书的计算代码与数据给公开仓库。

### 1.7 APS/PRL 规则（journals.aps.org/prl/authors 与 /authors/length-guide）

- **长度**：Letter 正文 3750 词（摘要与致谢之间，约 4 个期刊页）；不计入：标题、作者、摘要、参考文献、致谢。
  另可加最多 **2 页 End Matter**（附录等），不计入正文限额。
- **计数规则**：单栏图 = 150/宽高比 + 20 词；单栏表 = 13 + 6.5×行数；单栏公式每行 16 词；图注与脚注计入。
- **摘要**：指南页面未给硬性字数上限（本笔记未核实到具体数字）；惯例是一段、简短、写给广泛读者。
- **结构**：需要标题、摘要、引言（给足背景并放入文献语境）、中心部分、结论段、参考文献；面向"broad readership"。
- **SM**：论文必须 "stand on its own"，没有 SM 也要可理解、可信；SM 放"对理解主结果非必需"的信息，且要在参考文献中引用。
- **必需**：Data Availability Statement；实质性 AI 使用需披露；图表用无障碍配色，不只靠颜色区分。

### 1.8 计算机辅助证明在物理 letter 中的可信呈现（综合上面各例）

1. **定理先陈述**：正文里有一个编号的 Theorem（或 Claim），条件写全（噪声模型、基、轮数范围、电路）。
2. **证明梗概在正文**：把证明拆成 2–3 个引理，每个引理一句话说清它是"纸笔论证"还是"有限计算"。
   有限计算要说清：问题规模、精确求解器（不是启发式）、阳性对照（同一程序在已知会失败的电路上确实找到解）。
3. **可信度来自可复现，不来自"谁审过"**：两套独立实现结果一致；求解器的 UNSAT/无解结论可独立复算；
   证书文件（如 4224 个极小权重扩展逻辑算符清单、见证错误）公开。
4. **SM 写全细节**：编码方式、对称性约化的正确性论证、运行规模与软件版本、复现命令。
5. **Data/Code availability**：一句话 + DOI（Zenodo），不是内部路径。
6. **明确地位**：哪些是证明、哪些是数值证据、哪些是猜想，用词一致（SBB 的 Proposition/Conjecture 是很好的样板）。

### 1.9 这些论文共同"不写"的东西

内部流程（谁审计、哪个 agent 跑的、实验编号）、文件路径、内部代码名、日期和检索记录、"从正文移到这里"之类的修订痕迹、
写作自我约束（"我们不声称……"清单）、证据强度自评、未成功的长时间求解记录（除非它本身是科学信息）。
新颖性的论证压缩成引言里两三句带引用的话。

## 2. 我们草稿的诊断（按严重程度排序，行号指 `paper/draft.tex`）

总体判断：草稿的内容（尤其证明）是扎实的，问题在于它是**项目日志按时间顺序的转写**，
而不是围绕一个结果组织的 Letter。正文 3300 余词加 3 图 1 表，长度大致在限额附近，所以问题不是长度，是结构。

### 严重（必须改）

## 3. 目标结构：PRL Letter（约 3500 词，含 2–3 图 1 表）

**标题（候选）**：保留现标题或改为 "Interleaving lifts the circuit distance of the gross code to 12"
/ "Distance-12 single-ancilla syndrome extraction for the gross code"。标题应说出新结果，不必说方法。

**摘要（约 120–150 词，5 句）**
1. 背景：gross 码是 BB 码的旗舰，其电路实现的有效距离是 d_circ。
2. 缺口：SBB 证明非交错单辅助电路 d_circ ≤ 11，并提出交错电路能否达到 12 的开放问题。
3. 结果：我们给出一个交错的单辅助电路，并证明在 SD6 噪声下两个基、任意轮数 d_circ = 12。
4. 思想：保持扩展码（因此 d_ext = 11）不变，只调整时序，使所有极小权重扩展逻辑算符都不能提升为电路错误；证明为计算机辅助。
5. 代价与意义：周期 18 对 8，在色对称族中最小；顺带证明 SBB 猜想的 Fig. 12 电路 d_circ = 11；周期 8 是否可行仍开放。

**正文**
