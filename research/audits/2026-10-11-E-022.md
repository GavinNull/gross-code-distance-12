## 0. 我用了什么、没用什么

- **电路**：E-019 审计员从论文 Table IV/VIII 写的 `mycirc.Morph`（只读 import），按逐层门集合与实验者 `common.spec` 匹配
  （电路定义本身是被研究对象，匹配合理）。新码的多项式取自 `newcodes.NEW` 与 `random_codes.json`。
- **探测器 / 可观测量**：mycirc 的显式 Pauli 传播探测器 + 无噪声采样核验“探测器 = 全部确定性奇偶”（逻辑扭转把可观测量分出，
  每个实例都断言 n_obs = k）。**不用**实验者的扩展码、自然探测器、单轮归约或折叠。
- **噪声**：只读 `evaluators/noise.py` 的 sd6，stim DEM，CSS 投影（只保留同基底探测器）+ K 平移轨道分案（`inst.orbits` 逐项核验协变性）。
- **求解器**：`mdfs`（E-019 审计员写的，非实验者的 adfs）；另写了一个**完全不同算法**的下界检查器 `cenum.c`
  （枚举所有含轨道代表的“连通”列集合，不做基于校验子的剪枝）；CP-SAT（`a2_cpsat.py`）也试了，但 600 s 内证不出下界（lb = 0），无结论。
- **上界**：每个最小解经 `explain_detector_error_model_errors` 还原为物理故障，取同基底纯分量，以概率 1 的通道注入**含两基底全部探测器**的电路，
  要求 0 探测器、≥ 1 可观测量翻转。

## 1. 定理 1 与引理 2（逐步手查）

| 步骤 | 判定 | 说明 |
|---|---|---|
| 1. 每个故障等价于中点 Pauli U_f | 对 | 层 1–3、复位翻转、起点数据错误前推；层 4–6、测量翻转、终点数据错误后推。每层是 2N 比特完美匹配（mycirc 断言），CNOT 层内没有空闲位置；复位层 / 测量层左比特空闲 = data_start / data_end，右比特测量后到复位之间的错误被复位吸收。X 复位比特上的 X、X 测量比特上的 X 无效，正确丢弃 |
| 2–3. 探测器条件 ⇔ [U, Σ_p ∪ Σ_c] = 0 | 对（有前提） | Σ_c 探测器 m_r(S) ⊕ m_{r−1}(·) 只被 ρ(q) 触发；Σ_p 探测器 m_{r+1}(S') ⊕ m_r(R^c_{S'}) 的翻转 = b·S~' + ρ·R = [U,S']；我补查了 t ≥ r+2：Σ_c 探测器在 r+2 等于 [φ_c(b), S] = [b⊗I, Z_q] = 0，归纳成立。**前提**：(a) 每个中点稳定子在某一轮恰收缩到一个同基底测量右比特、扩张像右支撑只落在同基底测量比特上；(b) 探测器集合是**完备的**（等于全部确定性奇偶）。两者对每个电路是计算核验（analyse / mycirc 断言、采样完备性），不是对任意 morphing 电路的定理。写作时应把 (a)(b) 写成定理假设 |
| 4. 终点 / 起点 / 中点三种视角 | 对 | 中点行 [U,S'] = H~_c b + R·ρ，[U,S] = ρ_q，到 [H~_c b; ρ] 是可逆三角变换，行空间相同；逻辑行相差校验行的组合。起点对称 |
| 5. 逻辑条件 | 对（有前提） | 需要中点稳定子群 = M（k 相等，逐电路核验）且可观测量是完整的 k 个逻辑（mycirc 断言 n_obs = k）。b 附带的 X 测量右比特上的 X 是稳定子，不影响类 |
| 任意 R | **依赖折叠** | “单轮距离 = 扩展码距离”是证明；“任意轮数、含时间边界的 d_circ = 扩展码距离”依赖 Prop. 1 折叠（E-019 逐电路秩条件，非一般证明），且定理不处理初态复位 / 末读出边界。§2 的全电路结果是这两点的经验证据，不是证明 |
| 引理 2 | 对 | φ_p(x) 与 Σ_p 对易、φ_c(x') 与 Σ_c 对易，两条件分离，x ∈ ker H~_p、x' ∈ ker H~_c，乘积非平凡 ⇒ 至少一个非平凡 ⇒ |S| ≥ |x| 或 |x'| ≥ d~。d~ 必须取两端点码、该错误类型距离的最小值 |
| 推论 d_circ ≤ d~ | 对（限 sd6） | 需要左比特在复位 / 测量层有单比特 X 故障（sd6 空闲噪声）；在无空闲噪声模型下这个构造不直接成立，应写明噪声模型 |
| 机制 (C)“跨两半双旗簇” | 观察，非证明 | 11 个电路的分类是“三个简化模型都不等于 d_circ”的排除法，我重算得到同样的 11/20/26/18。见证形状佐证：bb124p_y_paper Z 的全电路见证 = 2 个初始左比特翻转 + 第 2 层（F_p†）与第 4 层（F_c）的 CNOT 故障，确实跨两半 |

结论：**证明在所述前提下成立，没有找到漏洞**。测量 / 复位层故障、两半之间的钩子、跨轮比较的探测器、可观测量都被正确处理。
需修订的是表述：把收缩结构与探测器完备性写成假设；“任意 R”和含边界的说法应标为“经折叠计算 / 全电路计算逐电路核验”。

## 2. 预测检验的独立性，以及我把独立检验扩展到全部 288 个电路

  所以 576/576 确实检验了“手推的扩展码 = stim 单轮实例”这一步（即定理 1 的单轮部分），但**不独立于折叠，也不独立于求解器**。
  日志把它与 auditor 检查合称“864 个独立检验实例”：数字本身也不对（576 + 330 = 906），且前 576 个不应称为独立。

  它对 d ≥ 5“太慢”的原因是用了**两基底全 DEM、无轨道分案**（8928 列）；CSS 投影 + 轨道分案后同一实例只有 1302 列，d = 6 在 0.1 s 内定案。

## 7. 发现的问题

1. （中）“864 个独立检验实例”数字错且夸大：E-019 管线与扩展码共享规格、端点码与求解器族，并非独立。本审计提供的 576 个整段 T = 4 实例可替换这一说法。
2. （中）定理陈述缺两条假设（收缩结构、探测器完备），“任意 R / 含边界”依赖折叠与计算核验。
3. （低）日志说 d ≥ 5 的整段 T = 4 检查“太慢”：原因是用了两基底全 DEM 且无轨道分案，CSS 投影 + 分案后 d ≤ 8 都是秒级，wm180 W = 9 约 2 分钟。
4. （低）推论 d_circ ≤ d~ 的构造依赖 sd6 的左比特空闲 / 复位故障，应写明噪声模型。
5. （记录）CP-SAT 无法证下界（600 s 内 lb = 0），未作为证据；cenum 在全 T = 4 实例上 W = 5 超时、W = 6 我按 PID 停止（5594 及循环中的后续 W = 6 进程），均不引用。
