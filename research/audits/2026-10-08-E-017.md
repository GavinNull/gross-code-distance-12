## 3. Prop. 1 of 2604.09797 (read in full, App. B) and whether it applies

What the proof uses (App. B, Fig. 24): (i) detectors split into D^(1)_t / D^(2)_t (duration 1 / 2 rounds); a
single fault between t and t+1 touches only D^(1)_{t+1}, D^(2)_{t+1}, D^(2)_{t+2}; (ii) every fault E between
t and t+1 has a mirror E' "at the same place" between t-1 and t (measurement flip <-> reset flip, gates in the
reversed order) that triggers the same D^(2)_{t+1} detectors, a time-reversed pattern elsewhere, and the same
logical effect; (iii) the fold: replace the last round's faults by their mirrors; weight cannot grow.
Scope stated in the paper: memory experiment with ideal preparation of an end-cycle code state and ideal final
end-cycle stabiliser measurement (footnote 11: not for stability experiments).

Points that the paper asserts but does not prove for a concrete noise model: that the fault set is closed under
mirroring (with "after the gate" noise like sd6, the mirror of a Pauli after CX g is the Pauli *before* g in the
reversed layer, i.e. g P g after g -- still a DEPOLARIZE2 component of the same gate; R/M-layer idles of left
qubits map to M/R-layer idles), and (ii) for the actual detector definitions. So I checked the premise by
computation instead of trusting it, in exactly the form the fold needs:

For the round-r part E of an undetected set F whose last round is r, F' = (F \ E) xor mu(E) is undetected with
the same logical value iff H_all(E) = H_all(mu E) and L(E) = L(mu E) for every E annihilated by Z_r, the
detectors that vanish on all faults of rounds < r. Linear-algebra test: rows of Psi(E) = [H_all(E) + H_all(mu E);
L(E) + L(mu E)] lie in the row space of Z_r restricted to round-r faults. (`c3_rounds.py`, "general fold".)
Also a *local* version with Z_r replaced by {y in span(D_r, D_{r+1}) vanishing on round r-1 faults} (a subspace
of Z_r, so stronger), which depends only on two rounds and therefore transfers to every T by periodicity.

Results (projected sd6 faults, my mirror map mu, noisy-boundary circuits):
- mu(f) is an actual fault of round r-1 for every fault f of round r (0 exceptions).
- general fold condition: holds for every r = 2..T, T = 2, 3, 4, 5, both bases.
- local fold condition: holds for every r = 2..T, T = 2..5, both bases (interior and final rounds, both parities).
- Remark: the paper's *per-fault* statements ("same D^(2)_{t+1} detectors", "same observables") do not hold
  literally in my detector basis (they are basis-dependent), and a naive block-wise version of the test fails
  for the final round (6 meta-check functionals sit in D_T but are blind to earlier faults); the correct
  basis-free condition above holds. This is a caveat on the paper's wording, not on the result.

Consequence (together with §2): for every T >= 1, any undetected logical F of the T-round memory circuit,
projected, folds to a set E' inside one round with |E'| <= |F|, L(E') = L(F) != 0, and zero syndrome; by
locality E' is a solution of that round's instance, which is equivalent to the round-1 instance. So
**d_circ(T) >= d(round-1 instance) for every T, with noisy reset/readout boundaries**, and the same for ideal
boundaries (projected, the ideal-boundary fault set and detectors coincide with the noisy-boundary ones: left
reset flip X vs left idle X/Y give the same projected component; final readout flip vs left idle in the last M
layer likewise; ideal-boundary X-type detectors are dropped by the projection anyway). The lead's separate
"noisy boundary, arbitrary R" question therefore does not need an extra argument: it is covered by the same
computation. The arbitrary-T step is "verified for T <= 5 + periodicity of the local condition", i.e. a
machine-checked hypothesis plus a written argument, the same standard as B7 of the E-014/E-015 audit.

  **d = 12** for both end-cycle codes, both types. [[144,12,12]] confirmed.
- Minimum stabiliser weight (nonzero element of rowspace(HX) or rowspace(HZ); `adfs any` on a parity check

  local Cliffords, so the morphing [[144,12,12]] is **not equivalent to the gross code** under those
  equivalences. The argument holds; note it says nothing about other notions of equivalence (e.g. Clifford

## 6. Scope and caveats

- Noise: sd6 as implemented by `evaluators/noise.py` (incl. idle noise in reset/measure layers). Faults are counted
  as single circuit-level Pauli components (= DEM error mechanisms). Lower bounds hold for any noise model whose
  fault set is a subset of sd6's (e.g. no idle noise); the weight-12 witness uses idle components after the
  reset layer (or initial-reset flips for t = 1), so for a no-idle model the upper bound would need re-checking for
  T where only interior rounds are available -- with a noisy initial data reset the t = 1 witness still exists.
- CSS relaxation: only same-basis detectors and the matching Pauli part are used; valid for lower bounds only;
  the upper bound is checked on the full circuit (all detectors).
- "Arbitrary T" rests on: exact checks for T = 1..5 (x), T = 4 (y, xy) plus the periodicity of the *local* fold
  condition and of the single-round instance (two-round structure, verified layer by layer). Written argument,
  machine-checked hypotheses -- same standard as B7 in the E-014/E-015 audit.
- Not checked: the paper layer order (swap23) variants' distance; f_y / f_xy upper bound; whether IBM's
  2605.21898 "morphing gross idle circuit" is this circuit (the journal already marks this as unverified;
  it is a literature question, outside this audit). No novelty check.

## 7. Issues found

1. (low, documentation) Journal stage 4 says single-round W = 11 used "Z: about 3.4e10, X: about 3.3e10 nodes";
   the lead's own output files sum to 2.82e10 / 2.87e10 (which my program reproduces). The R = 1 / R = 2 totals
   in the journal are right.
2. (medium, argument) The journal's application of Prop. 1 to sd6 was "论证，未另行计算". The premise does hold,
   but not in the paper's per-fault form for an arbitrary detector basis: with my (valid, time-local) detector
   basis the per-fault equalities "same D^(2)_{t+1}" and "same observables" are false, and a naive block-wise
   fold test *fails for the last round* (6 meta-check functionals that only the last round can see sit in D_T).
   What holds -- and what the fold actually needs -- is the basis-free condition of §3, now checked for
   T = 2..5, both bases. Any write-up should state Prop. 1's premise in that form (or cite this check) rather
   than "time-reversal symmetry holds".
3. (low) The lead's Z positive control (W = 12, case 0, 20 min) did not find a solution; the known witness lives
   in case 1 (my run finds one there in 150 s). Their control was therefore one-sided (X only).
4. (scope) The "noisy boundary, arbitrary R" question in the brief is not a separate problem: after projection,
   noisy and ideal boundaries give the same instances (§2, §3), and the fold covers both. The journal's plan to
   run R = 3 or to write an E-015-style gap argument is unnecessary.
5. (scope) Only f_x/repo-order has the full chain (construction, upper bound, lower bound, all T); f_y, f_xy have
   the single-round lower bound and T = 4 structure checks; swap23 has nothing.
