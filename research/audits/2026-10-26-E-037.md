一处差别：`decoder_setup.py` 不丢掉全零列（既不触发探测器也不翻转逻辑的故障），E-037 和我都丢掉了。全零列不可能出现在最小权重解里（去掉它更轻），所以不影响距离。

**“不在 PrepX 清零”**。我独立写了三套：忠实版（bit 并行帧模拟，PrepX 不清零）、全清零版、同一门序的 stim 电路（stim 物理清零）。在 gross 与 [[108]]、两种故障类型、R = 1、2、5、10、12 上三者的合并列集合逐个相同，连逻辑元组都相同（`results/E-037-audit/compare_dem_big.jsonl`）。理论上也说得通：残留在 X 辅助比特上的 X 帧在 PrepX 之后是 |+⟩ 的稳定子，之后经 CNOT 演化始终是当前态的稳定子，不改变任何测量结果，最终只在数据上留下 hx 行的倍数，与 lz 正交。

**与 E-037 自己的 DEM 对照**。我的 DEM 与 E-037 证书实例所用的 `*.cols.json` 在所有被比较的实例上逐列相同（探测器集合族相同；逻辑在模探测器意义下张成相同，实际上逐元组相同），包括四个 gross R = 12、四个 [[108]] R = 10 目标实例（SD6 由评估器公开入口 `memory_circuit` + `add_noise(sd6)` 生成）。

**“权重数的是单故障类”**。这对最小距离没有影响：k 个物理故障的效应是它们列的异或，同列的两个会抵消，所以列权重 ≤ k；反过来每一列至少由一个物理故障实现。因此“最少几个单故障”和“最少几列”相等。对外可以直接说“faults”。

**见证**。E-037 的八个见证在我的 DEM 上逐一复核：权重 10 / 8、探测器全静默、翻转的观测量与记录一致。IBM 模型的四个见证我又按其物理故障位置（周期、轮、门、比特）以概率 1 的错误通道注入我自己的无噪声 stim 电路（物理清零），全部探测器为 0，翻转的观测量与 E-037 记录逐个相同，去掉一个故障后有探测器触发（`witness_replay.jsonl`）。上界成立。

## 第 2 项：证明之外的两段论证 — 通过（给出证明，未找到反例）

记 F：Dx = 0，Lx ≠ 0，|x| ≤ W。设 F 有解，取全局最小权重解 x*（|x*| = w* ≤ W）。

**(i) 最小性约束**。T 静默且平凡指 DT = 0 且 LT = 0（**所有**观测量都不翻转；代码 `check_trivial`、`small_trivial` 的判据正是 `not d and not o`，我在 88 个 OPB 上用自己的 DEM 重验了全部 1 914 156 条基数约束和 8 702 388 条阻断子句的 T，全部静默且对所有观测量平凡）。

- 基数约束 Σ_T x ≤ b，b ≥ ⌊|T|/2⌋：若 |x* ∩ T| > |T|/2，则 x* ⊕ T 满足 D(x* ⊕ T) = 0、L(x* ⊕ T) = Lx* ≠ 0，权重 |x*| + |T| − 2|x* ∩ T| < |x*|，与最小性矛盾。注意这里没有“交换后权重仍 ≤ W”的问题：反证法只用到更轻的解存在，它自然也 ≤ W，而且“某个观测量为奇”由 L(x* ⊕ T) = Lx* 精确保持（不是“某个观测量”换成另一个，而是逻辑向量整个不变）。
- 阻断子句 ¬∧_T x：若 T ⊆ x*，T 非空，则 x* \ T = x* ⊕ T 是更轻的解，矛盾。
- **同时满足**：上面每一条都是“任何全局最小权重解都满足”的性质，各自独立地对同一个 x* 成立，不需要依次做交换，所以所有约束同时成立。要提防的反例形态是“对 T1 交换后破坏 T2”，这只在“以交换构造满足解”的论证里才会出现；这里的论证是反证，不存在这个问题。

**(ii) 轨道指示变量的对称破缺**。需要的前提只有一条：每个平移 σ 保持 F 的解集（σ 是列的置换，|σx| = |x|；D(σx) = ρ(Dx)，ρ 为探测器置换；在 ker D 上 Lσx = 0 ⇔ Lx = 0）。我用自己的代码在每个实例上逐个平移验证了这三点（`run_mincc.group`：每列的像的探测器集合是一列；span(D, L∘σ⁻¹) = span(D, L)；全部 72 / 54 个平移都通过，构成完整的群）。

对 σ(x*)：x* 是全局最小，σ 保持 F 的解集与权重，所以 σ(x*) 也是全局最小权重解，因而**自动**满足全部基数约束和阻断子句——这一步不需要 E-037 日志里写的“基数族、阻断族对群封闭”。取 o* 为 x* 碰到的第一个轨道，g ∈ x* ∩ O_{o*}，σ 把 g 映到 rep_{o*}（轨道是群轨道，σ 存在）；σ(x*) ∩ O_o = σ(x* ∩ O_o) 对 o < o* 为空，且含 rep_{o*}。令 h_o、e_o 取真值，H1、E2、SB 全部成立（逐条检查：H1 由定义；E2：e_o 为真意味着碰到某 o' < o，要么 o' = o−1，要么 o' < o−1 即 e_{o−1}；SB：o < o* 时 h_o 假，o = o* 时含 rep，o > o* 时 e_o 真）。所以加了全部附加约束的公式可满足。逆否即：附加后公式 UNSAT ⇒ F UNSAT。

因此 E-037 日志第 2、4 节的论证正确；比日志更强的说法是：基数族、阻断族是否对群封闭对可靠性无关，`dem_inst.py` 里的封闭断言是多余的保险。

**OPB 实际写的是不是这些约束**（`opb_audit.py`，全部 88 个实例，结果 `opb_audit.jsonl`）：逐行分类，任何无法归入下列类别的约束都判失败——探测器奇偶行（读出的列探测器集合族与我的 DEM 一一对应）、观测量奇偶行（与我的观测量模探测器张成相同）、权重行（全部 x，−W）、“某观测量为奇”行（恰为全部观测量行的 q）、基数约束、阻断子句、H1/E2/SB；辅助变量 a、b、q、h、e 只出现在应出现的位置；奇偶行的辅助位容量足够（容量不足会使公式过强，这是一个可能的错误来源，没有出现）；H1 给出的类恰好是我自己验证过的群的轨道，SB 的代表在其类中，E2 链完整。每个 OPB 的 sha256 与 runs.jsonl 中记录的相同。88/88 通过。（Z 型故障的 IBM 模型里有 72 / 54 个探测器从不触发，即最后一个无噪声周期的 X 校验，这些行写成“辅助位 = 0”，无害。）

**经验反例搜索**（`sat_test.py`）：对每个我独立枚举出的全部最小权重解（下表），检查它们是否违反对应 W = d−1 OPB 里的任何基数约束或阻断子句，以及每个解的轨道模式里是否有成员满足 SB。13 个实例（[[108]] 四个口径 R = 1、2；gross 四个口径 R = 1）全部 0 违反（`sat_test.jsonl`）。阴性对照：往 OPB 里加一条切掉某个最小解的非平凡基数约束，测试报 COUNTEREXAMPLE。
