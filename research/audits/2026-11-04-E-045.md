### A2. 投影与假设 H

A 类 = 第 0 轮探测器的坐标奇偶类（两基底各只有一个奇偶类，(1, 0)），与 `restrict.py` 相同。两基底：A 类 936 个（每轮 72 个、13 层），B 类 792 个；投影后 **8,784** 列；带 B 探测器的机制 51,048 个，其投影全部本身就是不带 B 的机制（违例 0）；纯 B 且不翻转观测量的 7,920 / 7,992 个丢掉；没有“不触发任何探测器却翻转观测量”的机制，也没有“A 部分为空却翻转观测量”的投影列；不带 B 的机制集合恰好等于投影列集合。全部与 E-045 一致。

## B. IBM 12+2 模型：每一个 R

### B1. 论证本身

我把三步逐条重证了一遍。

- **平移引理。** 帧模拟从零开始、线性、每个周期门序列相同；故障之前所有测量为 0，所以第一周期探测器（原始值）和以后的差分探测器在故障之前都是 0。第 c 周期的故障 f 在 N 周期电路里的列 = 第 0 周期的 f 在 N − c 周期电路里的列整体后移 c 个周期。正确（我的 `structure` 直接核了 R = 1..20：列集合 = ∪_{c<R} shift_c K0，全部相等）。
- **(E_T) 的精确检查。** 第 0 周期之后无故障，周期边界的帧状态 s_t（全部比特）按一个确定映射演化，状态空间有限，所以一旦 s_{t0+p} = s_{t0} 以后严格周期。第 t 周期的测量记录（t ≥ 1）是 s_t 的函数，L·data(s_N) 也是 s_N 的函数；要求它们在一个周期上为常数，就推出 t > t0 处探测器为 0、逻辑值不随 N 变。这覆盖所有 N，不是抽样。正确。
- **连通压缩。** F 是 k 列的不可检测逻辑；按“探测器集合相交”连边。每个探测器只被一个分量碰到，所以每个分量各自探测器异或为零；F 的逻辑是各分量逻辑之和，非零，所以某分量 C 本身是不可检测逻辑，|C| ≤ k。相邻两列共享一个探测器，探测器周期区间相交，所以 C 的周期区间之并是一个区间，长度 ≤ Σ 跨度 ≤ k·w。每列取一个表示 (c_j, f_j)，c_j ∈ [first_j − a, first_j]，于是 max c − min c ≤ k·w + a。整体下移 min c：探测器下标仍 ≥ 0、各列仍互异（平移是单射）、异或仍为零、逻辑不变；每个表示仍在 c_j − min c ≤ k·w + a < R′ = k·w + a + 1 的周期里，而由 (E_T)（N − c ≥ 1 + T）列不随总周期数变，所以下移后的 C 是 (R′, T) 模型里权重 ≤ k 的不可检测逻辑。需要的前提：(E_2)、平移引理、“每列至少一个探测器”（无探测器的单故障都不翻转逻辑，是零列，已丢弃）。证明没有漏洞。
- **对证书的依赖。** gross k = 9、w = a = 1 ⇒ R′ = 11；[[108]] k = 7 ⇒ R′ = 9。E-037 有 IBM 模型 gross R = 1..12、[[108]] R = 1..10 两基底的 VeriPB 证书（STATE 第 23 条，E-037 审计 CONFIRMED，且独立穷举复现了 R = 12 / 10 的目标陈述）。若 R ≤ 12（resp. ≤ 10）直接用证书，否则压缩到 R′。由于列集合随 R 只增（∪ 结构），权重更小的 C 落在更少的周期里也包含在 R′ 模型中。所以“每一个 R ≥ 1：gross 无权重 ≤ 9、[[108]] 无权重 ≤ 7”成立。
- **上界。** R = 1 的见证全在第 0 周期，由 (E_2) 它们在任何 (R, 2) 模型里列不变，所以对每个 R 都是不可检测逻辑。

## C. 推迟包含与单调性

### C1. 我对论证的复核

记 P 为周期。评估器 `unroll` 的起点 start_q = (σ + prep_q − P) mod P（“+P”的分支要求首个 CNOT 偏移 < 1，合法调度里不会发生），σ 取使结束层 P(R − 1) + max_q(start_q + dm_q) 最小者——argmin 与 R 无关，所以 R + 1 轮电路就是 R 轮电路每个辅助比特多一个实例。

**(Wb) ⇒ 推迟包含**（某基底下，读者 = 该基底类型的校验，写者 = 另一类）。取 R 轮电路中位置 u 的单故障，考虑 R + 1 轮电路位置 u + P 的同类故障。
1. *存在性。* 写者 / 读者实例 j 的门 → 实例 j + 1 ≤ R，存在；数据在 u + P ≤ last_R + P = last_{R+1}。日志没有提的一处：u 处空闲的数据比特在 u + P 可能正和某个写者的**第 0 实例**做 CNOT（该写者“第 −1 实例”本应在 u）。SD6 下那里是 DEPOLARIZE2，含 I ⊗ P 分量，作用在数据上的 Pauli 与原来的空闲错误相同、同样在该层之后，所以对应故障仍然存在。读者的第 0 实例不会出现在 u + P：(Wb) 说读者第 −1 实例都在 ≤ 0 读，即第 0 实例都在 ≤ P 读，早于 u + P（u ≥ ½）。数据复位错误（第 0 层之后的 X）对应 R + 1 轮第 P 层之后的同一 Pauli，那里的空闲 / CNOT 噪声都包含它。
2. *传播。* u + P 之后多出来的门只可能是写者第 0 实例（读者第 0 实例都在 ≤ P）。写者第 0 实例上没有故障；Z 基底下写者 CNOT 以辅助比特为控制，不把数据上的 X 带到别处，也不往数据上加东西（X 基底对偶）。所以 u + P + ½ 之后数据上的残余误差与 R 轮电路 u + ½ 之后相同，平移 P。
3. *探测器。* 数据上 u 时刻的沉积被读者实例 min{t ∈ 0..R−1 : read_t > u}（无则为最终读出 R）首先看到。(Wb) ⇒ read_{−1} ≤ 0 < u，所以这个有限指标 = min(体内指标, R)；u + P 在 R + 1 轮里的指标 = min(体内 + 1, R + 1) = 原指标 + 1。测量翻转 {t, t+1} → {t+1, t+2}（含最后一次测量与最终读出探测器的那一对）。最终读出探测器 R ↔ R + 1，观测量 = L·残余误差不变。第 0 轮探测器不会被平移后的列碰到。
4. 评估器只为记忆基底的校验放探测器（`memory_circuit` 里 `if typ != basis: continue`），所以另一类故障分量不进 DEM，不需要单独处理。（如果 DEM 里有另一类探测器，第 0 轮“随机参考”会让推迟包含失效，这一点对评估器之外的电路要另说。）

所以每个 R 轮的列推迟一轮后都是 R + 1 轮的列，R 轮的任一不可检测逻辑整体推迟后仍是 R + 1 轮的不可检测逻辑，权重相同：d(R + 1) ≤ d(R)。与 E-043 审计的 (Wt) ⇒ 原位包含合起来：一个基底只要满足 (Wb)、(Wt) 之一，d_circ 在该基底对 R 单调不增。

**“两个起点”引理。** 若所有 X 校验共用一个 prep 时刻、所有 Z 校验共用一个 prep 时刻（这正是“每类一个时序”所需的全部；CNOT 偏移可以逐校验不同），全电路只有两个起点 s_X、s_Z。最优展开的最小起点为 0（若都 ≥ 1，σ − 1 使每个起点减 1、结束层减 1，更优）。一个基底里读者起点 s_R、写者起点 s_W：
- s_R = 0 ⇒ 读的偏移 ≤ P − 1，read − P ≤ −1 ≤ 0，(Wb) 成立；
- s_W ≤ s_R ⇒ 所有起点 ≤ s_R，last ≤ s_R + PR − 1 < s_R + 1 + PR ≤ read + PR，(Wt) 成立。
两者都不成立要求 s_R > 0 且 s_W > s_R，与“最小起点为 0”矛盾。证毕。这比日志写的“(Wt) 不成立 ⇒ 读者起点为 0”多说清了一步：(Wt) 的成立只需要 s_W ≤ s_R，不需要任何关于 CNOT 偏移的条件。

### C3. 反例搜索的实际覆盖面

在引理范围内找反例是没有意义的（定理排除了），所以“反例搜索”真正有分量的只是范围外的电路。E-045 在范围外只测了 p18w（X 基底两个条件都不成立），DEM 原位 / 推迟包含 R = 1..4 都成立；Fig. 12 每类两个起点但每个基底都满足其一。300 个随机电路全是“每类一个时序”，它们只是对引理的数值核对，不是反例搜索。我也没有生成逐校验时序不同的随机电路（要保持合法和确定性需要专门的构造）。所以对外只能说“we know of no circuit whose distance increases with R”，并说明非单调只可能出现在逐校验时序不同的电路里、我们只检查了一个这样的电路。
