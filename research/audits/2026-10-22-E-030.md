## 1. d_circ = 10（CONFIRMED）

### 1a. 合法性与确定性（`a1_check.py`）
- 码与评估器的 HX、HZ 逐元素相等，k = 8。
- c11、c12、c13、ibm 都用我自己的编码器展开（逐层断言每个比特每层至多一个操作，每个校验 6 个 CNOT 严格夹在 prep 与 meas 之间，偏移互异）。R = 1..6 两基底下，无噪声 DEM 在 `allow_gauge_detectors=False` 下构建成功，采样全为 0。
- c11 的展开：起点 {0, 1}（Z 校验先起），所有校验 dm = 10 = D − 1。实验者的 `legal_c11_spec.json`（validate 0 问题、L0 全 pass、平移不变）我也读过，与此一致。
- **DEM 比对**：R = 3、p = 3e-3，四个电路、两基底、λ ∈ {1, 0, 0.1}，我的 DEM 与实验者 `common.noisy()` 的 DEM 探测器集合相同，按探测器集合合并后的概率最大相对差为 0.0（1440 列）。所以实验者的电路和噪声没有问题，我后面的 lift 和采样用的是同一个物理对象。
- `ibm90_spec.json` 与 `baselines.schedule.ibm_depth8(BBCode(15,3,[x^9,y,y^2],[1,x^2,x^7]))` 的规范化结果相同。

### 1b. 我自己的 lift（`a3_lift.py`，不同于实验者 lift9 的前沿 DP，每个 S 一次 SAT）
- 扩展码：按电路实际 CNOT 顺序（回绕时按 (t − prep) mod D 排序）造列。c11 两侧的列键集合与 E-028 审计列表的类 **完全相等**（代码里断言）。
- 每个 R、每个基底都断言了三件事：每个非零像是**恰好一列**（Lemma 1）；伸缩恒等式对每个 DEM 项、每个校验成立；observable 等于像的 L 部分。断言全部通过，包括回绕的 c11。
- 计数（全量，不提前停）：

| 电路 | R | Z 基 w8 / w8z / w9 | X 基 w8 / w8z / w9 |
|---|---|---|---|
| c11 | 1..25 每个 R | 0 / 0 / 0 | 0 / 0 / 0 |
| c12 | 1..4 | 0 / 0 / 0 | 0 / 0 / 0 |
| u16（阳性对照） | 1 | w9 = **315** | — |
| segctl（阳性对照，可分段） | 1 | **585 / 540 / 16830** | — |

阳性对照与 E-028 审计的数字逐个相同，w8z 分支也有命中，说明三条计数路径都能找到解。

### 1c. 回绕间隙论证（`a4_gap.py`，在我自己的编码器上）
- 起点在 R = 1..40 都不随 R 变；S = 1，dm_max = 10 ≤ D − 1，G = max(2·11 + 10 − 1, 11 + 1 + 10) = **31**。
- 插块：我对 R = 3..15 两基底逐层比较带噪电路（包括全部噪声通道）。对 x ∈ [1, 11R − 11] 都有 circuit(R) = circuit(R−1) 在 x 处插入 11 层，区间连续，lo = 1，c_hi = −11，与实验者的 `anyr_wrap_c11_spec.json` 一致。
- 算术：w = 9 时跨度 ≤ 8·30 = 240。删掉前面的块后 f1 ≤ lo + D − 1 = 11，所以 f_last ≤ 251。R + 1 轮能删后面一块，当且仅当 11(R+1) − 11 ≥ 251 + 21，所以 **R'_9 = 25**；w = 8 时 R'_8 = 22。这里用的是更保守的 2D − 1。
- 引理本身（沉降、分裂、删块）已在 E-024b 审计中逐条核过。归纳顺序是：≤ 7 由 d_ext = 8 加 Lemma 1 直接排除，然后 8，然后 9，不循环。lift 覆盖的 R ≤ 25 ⊇ {R'_8, R'_9}。
- 结论：c11 两基底、任意 R 下 d_circ ≥ 10。**这一结论现在有两条互相独立的证据链**：实验者的 lift9 R ≤ 25 + ccsearch R ≤ 12，以及我的 SAT lift R ≤ 25。

### 1d. 上界与 c13
- 权重 10 注入：先在我自己的码上核验实验者的两个支撑确是逻辑（HZ v = 0 且 LZ v ≠ 0；X 侧同理）。然后在我的电路里，在数据复位后放 10 个确定性翻转。c11、c12、c13、ibm 在 R = 1、2、5、11 两基底都是 0 个探测器、observable 翻转，所以 d_circ ≤ 10（这个上界与调度无关）。
- c13 与 c16（`a6_c13_sig.py`，我的编码器）：R = 1..12 两基底，DEM 的 (探测器集合, observable 集合) 签名集合**完全相等**，每个 R 的项数也相同。c16 任意 R 的 d_circ = 10 已由 E-028 审计确认，c13 的分离性和周期性见实验者的 `anyR_c13.log`（分离成立，属不回绕情形，用 E-028 的 R' = 12）。所以 c13 的结论成立。
- c12：分离、周期性成立（`anyR_c12.log`），我的 lift R = 1..4 为 0。R = 5..12 我没有独立跑，靠的是实验者的 lift9 加 ccsearch 两条路线。

**论文措辞**：“The period-11 circuit (wrapping) and the period-12 circuit (non-wrapping) both have circuit-level distance 10 under SD6 noise for every number of rounds and in both memory bases. The proof combines an exact lift over the complete weight-8 and weight-9 extended-logical lists for R ≤ 25 (period 11) or R ≤ 12 (period 12) with a round-reduction argument; the upper bound is attained by a weight-10 data logical.” 必须写明周期，以及 c11 的 Z 校验跨周期回绕。

## 2. 均匀族 P = 8–10 UNSAT（CONFIRMED，限定族）

**编码范围（读 `frame.Enc` 与 `cegar9.py`）**：
- |Hs| = 45，所以全部 X 校验共享同一组（标签 → 时刻），全部 Z 校验也共享一组，即平移不变。每个校验只有一个辅助比特：prep 在 s，CNOT 在 s + o（o ∈ [1, P−2] 互异），meas 在 s + P − 1，允许回绕。
- 合法性：每个数据比特上 6 个时刻 mod P 互异。确定性：每对重叠校验的两个共享比特满足 floor((t_z − t_x)/P) 相等。
- **每侧的 CNOT 顺序只能取某一个 d_ext = 8 类的 8 个顺序**（前 2 个可交换、后 2 个可交换、整体反转）。脚本遍历 4 × 4 = 16 个类组合，每个组合跑 P = 8、9、10。
- nogood 是体内帧模型中真实存在的权重 ≤ 9 不可检测逻辑（帧模型和 nogood 的可靠性已在 E-020/E-021/E-024b 审计中确认）。所以 UNSAT 的含义是：族内每个电路在足够多轮后都有权重 ≤ 9 的逻辑。

**重跑抽查**：A1A2A3B2B1B3×A1A3A2B3B1B2 P10、A1A3A2B3B1B2×A1A2A3B3B1B2 P9、A1A2A3B3B1B2×A1A3A2B2B1B3 P8、A1A2A3B2B1B3×A1A2A3B2B1B3 P10 全部 UNSAT（2 轮，cands = 0），与原日志相同。原日志里 P = 11 的同一族能找到 c11，起阳性对照的作用。

**不依赖编码的抽查（`a5_random_uniform.py`）**：在类 A1A2A3B2B1B3 × A1A2A3B2B1B3 中随机生成 6 个 P = 10 的合法确定电路（25 次尝试），用我自己的 lift 检查，6/6 在 R = 1 就有权重 8 的不可检测逻辑。这个检查很弱（随机电路本来就容易坏），只说明没有反例。

**范围限定**（论文必须写）：
1. 只覆盖两侧顺序都在 d_ext = 8 的均匀类中的电路。d_ext ≤ 7 的顺序类没有搜索；交错可以让 d_circ 超过 d_ext（c16 就是 8 → 10），所以不能排除它们。
2. 只覆盖平移不变的电路。子群族只做了部分（|H| = 15、9 UNSAT；|H| = 5、3 UNKNOWN），逐校验自由没有做。
3. 结论是体内（足够多轮）的，不是“任意有限 R”。

**论文措辞**：“Within translation-invariant single-ancilla schedules whose X- and Z-check CNOT orders both lie in one of the four order classes with maximal extended-code distance (d_ext = 8), no schedule with period P ≤ 10 (wrapping allowed) reaches bulk circuit distance 10 (SAT, 48 of 48 instances unsatisfiable); period 11 is attained.” 不能写 “11 is the minimal period for d_circ = 10”。

## 3. LER（λ = 0 方向 CONFIRMED；幅度与单调性 UNVERIFIED；λ = 1 措辞要改）

### 3a. 公平性
- 模板、探测器、R：两电路都走评估器的 `memory_circuit`，都用局部探测器，R = 10，Z、X 分别采样，ε = ε_Z + ε_X。我的编码器独立复现出同一个 DEM。
- 噪声：λ 只改空闲 DEPOLARIZE1。`rescale_idle` 断言每个 DEPOLARIZE1 的目标恰好是本层未被作用的比特，电路里只有 R/RX/CX/M/MX。我自己的加噪器只在“未被作用的比特”上加 λp，与实验者的 DEM 完全相同（1a）。λ = 0 时两电路每轮的 DEM 质量都是 0.497（probe.json），故障质量相同，比较只反映结构。
- 解码器：两电路用同一组参数。BP-OSD 是 min-sum、10000 次迭代、ms_scaling 0、OSD-CS 7；Relay 是 relay5。
- IBM 电路：spec 与 `ibm_depth8` 相同，该函数已在 E-002 审计中逐 round 对过 2308.07915 Table 5。多项式项序 A = x^9 + y + y^2、B = 1 + x^2 + x^7 与 Table 3 一致。阳性对照：λ = 1、p = 1e-3 时 6.1e-6 [4.5, 8.5]e-6，IBM Table 1 为 5e-6，区间包含 5e-6。（论文需注明：我们 Z、X 分别采样后相加；Table 1 未给原始计数。）
- 预注册：c17c816 的预测 5 写了 λ = 0 会在 3e-3–4e-3 赢（50%），yaml 之后没改过。λ = 0 不是事后挑出来的。

### 3b. 原始 csv 复算（`a8_recheck_csv.py`，自己解析、Jeffreys MC）
日志表中全部比值都复现到 2–3 位有效数字。例如 λ0 BP-OSD 3e-3 为 0.442 [0.331, 0.589]，2e-3 为 0.375 [0.257, 0.546]；Relay 2e-3 为 0.249 [0.119, 0.479]；λ1 BP-OSD 为 5.7–9.1，**λ1 Relay 为 8.6 / 17.1 / 14.3 / 8.7 / 9.5**（5e-3 到 1.5e-3）。

### 3c. 独立重采样（`a2_sample.py`：我的电路、加噪、逻辑、DEM 矩阵，stim DEM 采样器新种子 30300000+j，`ldpc.BpOsdDecoder` 使用 IBM 参数；实验者用的是 stimbposd + sinter）
λ = 0，p = 3e-3，R = 10：

|---|---|---|---|---|
| c11 | 83 / 105300 | 89 / 106300 | 1.63e-4 [1.40, 1.89]e-4 | 1.42e-4 [1.15, 1.75]e-4 |
| ibm | 88 / 70300 | 112 / 70300 | 2.85e-4 [2.48, 3.27]e-4 | 3.21e-4 [2.64, 3.91]e-4 |

- **c11/IBM = 0.57 [0.47, 0.70]**（我的数据）。实验者是 0.44 [0.33, 0.59]。两者区间重叠，各点的绝对值也都在对方区间内或贴边，所以方向（显著 < 1）是独立复现了的。

### 3d. λ = 0 的物理含义（必须写进论文）
λ = 0 去掉了所有空闲噪声，周期变长不付出任何代价。所以这个比较只说明 d_circ 从 8 提到 10 的结构收益在实用 p 就能体现，不说明 c11 在真实硬件上更好。
- λ = 0.1 时就已不可分辨，5e-3 处 BP-OSD 还略差（1.34 [1.01, 1.76]）。
- λ = 1 时输 5.7–9.1 倍（BP-OSD）、8.6–17 倍（Relay）。
- 每 unit-duration 层的比值（× 8/11）在 λ = 0 下反而更偏向 c11，这只是“空闲免费”的假设在起作用，不要在正文里用它加分。

**论文措辞**：“In a noise model without idle errors (SD6 with the idle channel removed, λ = 0), the period-11, d_circ = 10 circuit has a lower per-round logical error rate than IBM's depth-8 circuit at every sampled p between 2×10⁻³ and 5×10⁻³ with both BP-OSD and Relay-BP (at p = 3×10⁻³, BP-OSD: 0.52 [0.44, 0.62], pooled from two independent sampling pipelines). With idle errors at 10% of the gate error rate (λ = 0.1) the two are statistically indistinguishable, and under standard SD6 (λ = 1) the new circuit is worse by a factor of 6–9 (BP-OSD) and 9–17 (Relay-BP) per round. The advantage therefore exists only when idling is nearly free.”
**不得写**：“beats IBM”（不带 λ = 0 的限定）；“0.37 at 2e-3” 作为唯一的头条数字（失败数少，且 3e-3 的独立复现比原值高约 30%）；“ratio decreases monotonically with p”；“loses by 6–9×”（不注明解码器）。

## 4. 领头阶计数（计数与算术 CONFIRMED；用法要加限定）

- **IBM Z 基独立重算**（`a7_ibm_count.py`）。这条路线与 ccsearch 是不同的算法：先用我的码按 IBM 的顺序造扩展码，用 MITM 求出完整列表，再在我的 DEM 上用 SAT 枚举全部提升，最后映射回普通 DEM 签名去重。
  - IBM X 侧 d_ext = **7**（权重 7 有 315 个，权重 8 有 9630 个）。所以权重 8 = 8 列，或 7 列加 1 个零像项（计数论证只有这两种）。
  - 结果：R = 1、2、3 分别为 **90、405、720**，与实验者 `lead_ibm_W8.json` 逐个相同，即**每轮 315**。
  - IBM Z 侧 d_ext = 6（权重 6 有 270 个），所以 X 基的权重 8 还要算“6 列 + 2 零像项”和“重复列对”等混合情形，我没有实现。**X 基的 540/轮没有独立重算**。
- c11 权重 10 每轮 24507（Z 和 X）：R = 2→3→4 的差分恒定，X 与 Z 相同。这依赖 ccsearch 的 enum 模式（E-029 已审计 decide/enum 的完备性论证），lead.py 也在 DEM 上逐个重验了每个逻辑。我没有独立枚举（需要处理 10 = 10 列 / 9 + 1 / 8 + 2 / 8 + 重复对等多种混合，代价太大）。
- 算术（从 json 复算）：
  - A4(IBM, Z+X) 为 λ0 1.364e4、λ0.1 1.678e4、λ0.3 2.495e4、λ1 8.317e4。
  - B5(c11, Z+X) 为 λ0 8.076e6、λ0.1 2.041e7、λ0.3 9.43e7、λ1 2.789e9。
  - p\* = A4/B5 为 1.69e-3、8.2e-4、2.65e-4、2.98e-5，与日志一致。注意 `lead_c11_W10.json` 已被 X 基的运行覆盖，Z 基数值只留在 `lead_c11.log` 里，建议另存。
- **限定**：
  1. 这是理想（最可能错误）解码器下的并集形式估计，不是界。
  2. 日志说 p\* 是“偏低估计”只说了一半。忽略 IBM 的 p⁵ 项会让 p\* 偏低，忽略 c11 的 p⁶ 项（权重 11、12）会让 p\* 偏高，净方向不确定。
  3. 实测在 λ = 0 时 5e-3 就已经赢了，而理想估计给出 p\* ≈ 1.7e-3，两者方向相反。结构核也显示两种实际解码器在 c11 权重 10 逻辑的 4 子集上会失败（BP-OSD 约 2%），所以理想领头阶既不能描述采样区间，也不能描述实际解码器的渐近行为。
  4. λ = 1 的 3e-5 只能作为“实际 p 下不存在交叉”的旁证。

**论文措辞**：“IBM's depth-8 circuit has 315 (Z basis) and 540 (X basis) minimum-weight (8) undetected logicals per round, the new circuit 24507 of weight 10 per round in each basis (exact enumeration; the Z-basis IBM count was reproduced with an independent method). A union-form leading-order estimate for an ideal decoder places the break-even at p ≈ 2×10⁻³ for λ = 0 and ≈ 3×10⁻⁵ for λ = 1; this is indicative only: it neglects higher-order terms of both circuits and does not describe BP-OSD or Relay-BP, which fail on some weight-4 subsets of the new circuit's weight-10 logicals.” 可以放进正文作机制说明，但不能把 p\* 写成预测。

## 发现的问题
