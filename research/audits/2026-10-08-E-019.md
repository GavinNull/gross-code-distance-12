## 0. 独立性说明（先读）

- **电路是我从论文文本重新写的**：`mycirc.py` 只依据 arXiv:2407.16336v3 的 Table IV（= Table II 去掉 a1 = b1 = 1）、
  Table VIII（第 2 轮 CNOT 反向）和 **Table IX**（Table VIII 电路的 (a1,a2,a3)/(b1,b2,b3) 显式排列），
  本地文本副本 `scratchpad/lit/2407.16336.txt`。没有 import `search/experiments/e019`，也没有用 E-017 审计脚本。
- **探测器是我自己推导的另一种方式**：由 Pauli 传播显式写出（收缩稳定子的测量记录 ⊕ 它上一半周期扩张像在右比特上的
  测量记录；末轮为端点码稳定子的读出奇偶），再用无噪声采样核验确定性；可观测量用“逻辑随机化”（初态后以 1/2 概率施加
  C~1 的 k 个共轭逻辑算子）把探测器空间和逻辑空间分开，核对 n_obs = k。实验者用的是采样核 + 时间局域块的方法。
- **故障集合直接用 stim 的 DEM**（噪声由只读的 `evaluators/noise.py` 的 sd6 / `uniform_depolarizing(idle=False)` 插入），
  不是自写的故障枚举与帧传播。
- **求解器是新写的**：`mdfs.c`（按未满足行分支、兄弟禁用、popcount/最大列重剪枝、可选平移轨道分案），没有沿用
  `adfs.c`/`dfsw.c`。另写了一个**无搜索树的 meet-in-the-middle 判定器** `t4_mitm.py`（≤3 列子集的校验子匹配）做交叉验证。
- 只在两处读了实验者的东西：(i) `t8_compare.py` 把我的 80 个电路与其 `common.spec()` 做逐门比对；
  (ii) `t9_theirwit.py` 把其 JSON 里记录的见证注入**我的**电路。折叠条件（Prop. 1）一项是审读其代码与输出（§5）。

## 1. 电路族清单（优先级 3）

- 80 个电路 = 10 个（母码, 同态）× {Table IV, Table VIII} × {(a2,a3) 顺序} × {(b2,b3) 顺序}。我自己的构造：
  每层是 2N 比特的完美匹配；每个 mid-cycle 稳定子在 F_i 下要么收缩到被同基底测量的单个右比特（个数 = 测量数），
  要么扩张且右支撑只落在同基底测量比特上（Pauli 传播推导，`check_contraction`）；两个端点码 k = 12（[[108]] 为 8）；
  端点码生成元权重 Table IV 全为 9，Table VIII 为 9 或 11（与论文 App. G.2“至多 11”一致）。T = 3 记忆电路在 stim 中
  确定（DEM 可建），n_obs = k，CSS 模式无额外探测器（`t0_build.py`，`results/E-019-audit/t0_build.json`）。
- **逐门比对**（`t8_compare.py`）：我的 80 个电路与实验者 80 个变体**一一对应、逐层门集合与测量集合完全相同**（80/80）。
  标签对应：f_x、f_y 下 我的 IV(sa,sb) = 实验者 paper(00)/std10(01)/std01(10)/repo(11)，VIII(00/01/10/11) = swap2/sw01/sw10/sw11；
  f_xy 下因为“prepared”顺序不同，对应关系两位都取反（IV00 = repo、IV11 = paper、VIII00 = sw11、VIII11 = swap2 等）。
- **端点码精确距离**（`t1_endcycle.py`、`ec288.txt`，mdfs 穷举，两端点码 × 两种错误类型，[[288]] 只算 C~1 两种类型）：
  56 个小母码电路与 24 个 [[288]] 电路的 d̃ **全部与日志表一致**（[[36,12,3/4]]、[[54,8,8/7]]、[[72,12,5/6/7/8]]、[[144,12,12/10]]）。
- **论文 Table IX 解决了日志说“论文与仓库都没有明确规定”的排列歧义**（日志漏读了 Table IX）：Table IX 明确列出 Table VIII
  电路的排列——[[36,12,4]]（f_x、f_y、f_xy 各两种）、**[[72,12,8]]（f_x，d̃_circ ≤ 6）**、[[72,12,7]]（f_y，≤ 7）。
  我按 Table IX 的排列直接构造，得到的正是实验者的 f_x/f_y sw01/sw10、f_xy swap2/sw11（[[36,12,4]]）、f_x sw01/sw10（[[72,12,8]]）、
  f_y sw01/sw10（[[72,12,7]]），端点码参数与 Table IX 完全一致。所以：
  - 论文的 [[72,12,7]] 按 Table IX 的排列**如实给出 [[72,12,7]]**，日志“作者的输入顺序与 Table I 书写顺序不同，未核实”可以关掉。
  - **[[72,12,8]] 不是“新发现”**：论文 Table IX 已列出它，并给出 BP-OSD 上界 d̃_circ ≤ 6。E-019 的贡献是证明这个上界是紧的（= 6）。
  - 主文说“三个电路距离和上界都更大”，App. G 说“两组改进了电路级上界”（[[36,12,4]] 与 [[72,12,7]]）；
    [[72,12,8]] 只改进了端点码距离、没有改进电路级上界——这与 E-019 的 6 一致，不存在“第三个未点名”的谜。
- **Table IV 的 (a2,a3)/(b2,b3) 顺序**：论文 Table IX 图注说 Table IV 电路“与 A、B 的项顺序无关”（依据是端点码在 a2↔a3、b2↔b3 下不变，
  Corollary D.3）。端点码确实不变（我算的 4 种顺序 d̃ 相同），但**电路级距离不是**：[[54,8,8]] 上 4 种 Table-IV 合法顺序给出 6、6、7、7。
  决定因素是 (b2,b3)：Table IV 第 1 轮用的 b3 = x² 时为 6（我的 IV00、IV10 = 实验者 paper、std01），b3 = x 时为 7
  （IV01、IV11 = std10、repo）。实验者的“paper 序”= Table IV + Table I 中剩余两项的书写顺序，这是一个合理读法，但 Table II/IV
  本身没有固定这个顺序，**不能写成“论文 Table II 的电路是 6”**，只能写“Table IV 的四种合法项序中有两种 d_circ = 6”。

结论：80 个电路的清单与论文表一致，CONFIRMED；附带两处日志纠错（Table IX 已给出排列；[[72,12,8]] 已在论文中）。

## 2. 精确 d_circ：在我自己的电路上重算（优先级 1、2、3）

方法：stim DEM（sd6，p = 1e-3 只影响概率不影响结构）→ mdfs 精确穷举（W 从小到大，第一次有解即 d_circ）。
CSS 投影（只用同基底探测器）对下界是松弛；对这些 CSS 电路，每个投影列都能由一个纯 X（Z 记忆）/纯 Z（X 记忆）分量实现，
而纯 X 故障不会触发 X 基探测器，所以投影最小值 = 全电路最小值；我又在含两基底全部探测器的电路上做了注入核验（§3）。

## 3. 见证：注入到含两基底全部探测器的电路（优先级 1、2）

`t6_inject.py`：从 CSS 实例取一个最小解 → stim `explain_detector_error_model_errors` 得到物理故障位置 → 只保留同基底分量
（它本身就是同一个噪声通道的一个 Pauli 分量）→ 以概率 1 的 `X_ERROR/Z_ERROR` 注入到**含 X、Z 两基底全部探测器**的无噪声电路
（[[54]] 274 个探测器，[[72,12,8]] 约 400 个）→ 要求 0 探测器、≥ 1 可观测量翻转。
（第一版用确定性 X 门注入，stim 会把它算进无噪声参考，导致探测器与可观测量都“0 翻转”的假阴性；改成概率 1 的噪声通道后正常，见 §7。）

无空闲噪声模型、只保留单个**内部**半周期（T = 5 的第 3 个）的噪声，16 个实例（8 电路 × 2 基底）**全部通过**：

| 电路 | 权重 | 故障组成 | 触发探测器 | 翻转可观测量 |
|---|---|---|---|---|
| [[54]] paper（IV00）Z / X | 6 / 6 | **6 个 CNOT 故障**（2 个双比特分量 + 4 个单比特分量） | 0 / 0 | 3 / 4 |
| [[54]] std01（IV10）Z / X | 6 / 6 | 6 个 CNOT 故障 | 0 / 0 | 3 / 4 |
| [[54]] repo、std10、swap2、sw10 Z / X | 7 | 7 个 CNOT 故障 | 0 | 1–6 |
| [[72,12,8]] sw01、sw10 Z / X | 6 | 6 个 CNOT 故障 | 0 | 2–9 |

所以：**这些 < d̃ 的结果不依赖空闲噪声、不依赖初态复位噪声、也不只出现在第一轮**——在任一内部半周期里，只用 CNOT 故障
就有权重 6（7）的未探测逻辑错误。实验者在日志“噪声口径”一段里的保留（“大多数 < d̃ 见证用左比特复位翻转，其余情形依赖初始
复位噪声或空闲噪声，未另行重新求最小值”）**过于保守，可以去掉**：无空闲模型、任意中间轮的 d_circ 与 sd6 相同。

实验者自己记录的见证（`t9_theirwit.py`）：他们的第 1 轮 = 我电路的第 2 个半周期（起始收缩电路不同，靠其 CX 对在我电路中的位置确认）。
平移一个半周期后注入我的全探测器 T = 4 电路：[[54]] paper Z/X、repo Z/X、[[72,12,8]] sw01 Z/X、sw10 Z/X，**8/8 均为 0 探测器、
3–9 个可观测量翻转**。其中他们的“左比特复位翻转”在我的内部半周期里变成复位层的空闲分量（sd6 合法，无空闲模型下不存在）——
这正是他们那段保留的来源；但 §3 上表说明换成纯 CNOT 故障同样存在同权重的见证。

## 5. Prop. 1 的折叠条件是否逐电路检查（优先级 5）

- 代码审读（`search/experiments/e019/instance.py` 第 384–466 行）：对每个电路、每个基底、r = 2..4，
  (a) 镜像映射 μ 把第 r 轮每个故障映射为第 r−1 轮的**单个**故障（`mirror_not_a_fault` 计数必须为 0）；
  (b) 一般形式：Ψ = [H_all(E)+H_all(μE); L(E)+L(μE)] 的行落在 Z_r（对早于 r 的全部故障为零的探测器泛函）限制到第 r 轮故障上的行空间；
  (c) 局部形式（只用 D_r、D_{r+1}，对第 r−1 轮故障为零）。三者都是秩条件，不依赖 μ 是否“物理上”是镜像，只要它把单故障映到单故障，
  折叠就不增权重——论证正确。镜像映射的层偏移规则沿用 E-017 的标准结构，但对 Table VIII 电路是否合适并不需要相信：
  秩条件不成立时 `fold_ok` 会是 false。
- 输出核查：160 个 `solve_*_T4.json` 的 `checks` 中 `fold_ok`、`all_rounds_equivalent`、`stim_eq_mine`、`locality_violations = 0`
  **全部为真**（160/160）。所以“逐电路检查了”属实。
- 我没有独立重写折叠检查。作为不依赖折叠的旁证：56 个小母码电路我直接在整段 T = 4 电路上求了最小值（§2.1），8 个 < d̃ 电路
  还在 T = 5 的内部窗口上求了（§2.2），[[288]] f_x sw11 在整段 T = 3 电路上做了 W = 9 穷举（§4），结果都与单轮实例一致。
  对 [[288]] 的“任意 T”结论，仍依赖实验者的折叠计算（我审读过代码并核对了输出标志）。
