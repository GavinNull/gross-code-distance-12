## 1. 情形分析 (a)/(b)：CONFIRMED

我从头推了一遍，不看他们的论证。

设 F 是 R 轮电路里一个不可检测的逻辑错误，|F| = 9。每个故障 f 的“像” = 电路结束时它留在数据上的 X 部分（Z 基）对 (H_Z, L_Z) 的作用，按扩展码列的键合并。

- **Lemma 1（每个故障的像是 0 或恰好一列）**：我没有靠推理，而是在 DEM 上直接断言。做法与项目相同思路但自己实现：在我自己的电路末尾加 45 + 8 个“像 observable”（H 行、L 行在最终数据读出上的奇偶），stim 就把同一 DEM 项里像不同的故障分开。R = 1..12、两基底，每一项的像都是 0 或我自己构造的扩展码的一列（`a5_lift.py` 的断言），225 列全部被实现。顺带：增广后的项数与原 DEM 项数相同（540 / 990 / …），即每个 DEM 项的像本来就唯一。
- **伸缩恒等式**：每个 DEM 项、每个校验 c，c 的各轮探测器的 XOR = 像的 H 部分第 c 位（`a9_telescope.py`，R = 1, 2, 3, 5 两基底 0 违例）。所以 F 不可检测 ⇒ 像之和的 H 部分 = 0；且 observable 翻转 = 像之和的 L 部分（`a5` 断言我的 observable 等于像的 L 部分）。于是像之和是一个扩展逻辑。
- **计数**：设 z 个故障像为 0，其余非零像里有 c 对相同的列互相抵消，剩下的不同列组成扩展逻辑 x，|x| = 9 − z − 2c ≥ d_ext = 8。只有两种解：z = c = 0（9 个不同非零列，情形 a）或 z = 1, c = 0（8 个不同非零列 + 1 个零像故障，情形 b）。**“7 列 + 2 个零像”给出 |x| = 7 < 8，不可能；任何一对重复列都使 |x| ≤ 7，不可能。**情形分析是完整的。
- **“零像 = 读出翻转”**：对 c16 成立，而且是逐项核过的：每轮恰好 45 个带探测器的零像项，**全部**是探测器 {(c, j), (c, j+1)} 的读出翻转模式（R = 1..12 两基底，`zero_readout_pattern` = `zero_terms_with_dets`）。物理原因：Z 辅助比特上的 X 错误（复位、空闲、CNOT 后）只翻测量；X 辅助比特在第一个 CNOT 之前的 X 错误传播成整条稳定子，交错顺序满足“每对 X/Z 校验共享比特上先后次序为偶数”（我核了 405 对，全部偶数），所以对同轮 Z 测量不可见，不产生探测器。
- **零像项是否收集完整**：项目代码（`lift.build_groups`）不是按“读出翻转”这个描述去找，而是把 DEM 里所有像为 0 且有探测器的项都放进候选组；我的实现同样如此。所以完整性不依赖这句物理描述。限制“零像项的探测器 ⊆ 8 个组支撑的并集”是对的（并集外的探测器没有其他项能抵消）。

**论文措辞**：“Each fault's residual data error is either trivial or equal (modulo stabilisers) to a single extended-code column; we verify this on every term of the detector error model. Since d_ext = 8, a weight-9 undetected logical consists either of nine faults with distinct non-zero images forming a weight-9 extended logical, or of eight such faults forming a weight-8 extended logical together with one fault of trivial image; in this circuit the latter are exactly the ancilla readout flips.”

## 2. 585 / 16830 列表的完整性：CONFIRMED

- 我直接从 c16 的实际 CNOT 顺序构造扩展码（数据列 + 每个校验的真后缀，按 (H 列, L 列) 合并、丢零列），225 列，平移群 45 元，5 个轨道。
- 算法：**meet-in-the-middle**（`mitm.c`）。按轨道情形划分（集合含 rep_k 且不含序号 < k 轨道的列，平移后穷尽），剩下 w−1 列按排序拆成前 ⌊(w−1)/2⌋ 和后 ⌈(w−1)/2⌉ 两半，后半按综合征排序后二分查找，要求前半最大 < 后半最小，每个集合恰好出现一次；然后用 45 个平移展开去重，逐个重验。这枚举的是**所有**权重 w 的扩展逻辑，不是“综合征极小”的子集。
- 结果（两侧完全相同）：w = 1..7 全 0（即 d_ext = 8），w = 8：**585**，w = 9：**16830**。与项目 `w8_*_all_A1A2A3B2B1B3.pkl`、`w9_*_all_A1A2A3B2B1B3.pkl` 用评估器的 HZ/LZ、HX/LX 换算键后**集合逐个相等**，列集合也相等（即 c16 的扩展码确实等于他们用的类代表 A1A2A3B2B1B3 的扩展码）。u16、segctl 也同样一致。
- “症状极小”论证：我也自己推了一遍，正确（权重 9 逻辑的真子集若综合征为 0：若它是逻辑，权重 ≤ 8 ⇒ = 8，补集是单列且 H = 0，单列不是逻辑也不是零列，矛盾；若它非逻辑，补集是权重 ≤ 7 的逻辑，矛盾）。不过有了全量 MITM，这一步已经不需要。
- 先前我试过用 SAT 加阻断子句枚举（`a4_extlist.py`），连“≤ 7 UNSAT”都 10 分钟不返回，已放弃；这只是 SAT 不擅长 XOR + 基数约束，不影响结论。

## 4. 任意 R：CONFIRMED

我自己重推了一遍，前提在我的编码器上是构造性的（所有校验 prep 0、meas 15、CNOT 在 1..12，第 j 轮完全落在第 j 个 16 层块里），项目的 `anyR_c16.log` 也核过分离（S）和周期性（T，R = 3..14）。

- 权重 ≤ 7：任意 R 不可能（Lemma 1 在每个 R 都成立——块是周期复制的，我在 R = 1..12 直接断言过——加 d_ext = 8）。
- 拆分引理：若 F 不可检测且其故障块跨度内有一个空块 j，则 F1 = 块 < j 的故障单独也不可检测（它在块 j 结束时只留数据错误，之后每轮测得相同综合征，最后与数据读出一致；块 ≤ j 的探测器与 F 相同，因为后面的故障影响不到它们），F2 = F \ F1 也不可检测（线性），且两者之一翻转 observable。所以“任意 R 无权重 ≤ 7” ⇒ 权重 8 的跨度 ≤ 8 块；有了“任意 R 无权重 ≤ 8”，权重 9 的跨度 ≤ 9 块。顺序（先 8 后 9）是对的，不循环。
- 删空块：周期性允许在第 2 块之后、最后一块之前删块，所以 R' ≤ 2 + 9 + 1 = 12。我留意了一个细节：第 0 块的第 0 层数据是复位（只有 X_ERROR），其他块同一层是空闲（DEPOLARIZE1）；但项目只删第 2 块之后的块，不涉及这个差异；即使涉及，Z 基下 DEPOLARIZE1 的 X 分量与复位翻转效果相同，也不会出问题。
- R = 1..12 两基底的 w8、w8z、w9 全 0 已由三套 lift 实现确认，所以任意 R、两基底 d_circ ≥ 10。

## 5. 合法性、确定性、码、上界：CONFIRMED

- **码**：自己按 x = S_15 ⊗ I_3、y = I_15 ⊗ S_3，A = x^9 + y + y^2，B = 1 + x^2 + x^7，H_X = [A|B]，H_Z = [B^T|A^T] 构造，与评估器的 HX、HZ 完全相等；n = 90，rank H_X = rank H_Z = 41，k = 8；SAT 证明两类逻辑都没有权重 ≤ 9，且有权重 10 的，所以 d = 10；权重 10 的 X 型逻辑恰 558 个（与日志一致）。多项式与 `research/literature/qldpc-code-catalog.md` 记录的 2308.07915 Table 3 一致。
- **合法性**：每个数据比特每层至多一个 CNOT（0 冲突）；每个校验的 6 个 CNOT 恰好覆盖其支撑、时间互异、严格位于 prep 与 meas 之间；评估器 `validate_schedule` 返回空，L0 在 R = 1、3 两基底全部通过。
- **确定性**：405 对有交叠的 X/Z 校验，共享比特上 X-CNOT 先于 Z-CNOT 的个数全部为偶数；无噪电路采样所有探测器和 observable 恒为 0；stim 构建 DEM 不报非确定探测器。
- **单辅助、交错、平移对称**：每个校验一个辅助比特；X-CNOT 层 {1,3,5,6,8,10}，Z-CNOT 层 {2,4,6,7,9,12}，第 6 层两种都有，数据比特的循环序列是 XZXZXZ，不可分段。所有 X 校验同一个（标签, 时间）签名，所有 Z 校验同一个，所以 45 个平移都是电路的对称。
- **上界 d_circ ≤ 10**：在我的无噪电路里把一个权重 10 的数据逻辑放成 10 个“复位后翻转”故障（Z 基 X_ERROR、X 基 Z_ERROR，都是 SD6 的故障位置），R = 1, 2, 3, 6, 10, 13 两基底都是 0 个探测器、observable 翻转。这个上界对任意电路都成立（它不依赖调度），所以 d_circ = 10 = d 是紧的。

## 6. “任何顺序 d_ext ≤ 8” 与 “可分段最优恰为 8”

## 论文可用措辞（汇总）

- 主结果：“We give an explicit single-ancilla, interleaved syndrome-extraction circuit for the [[90,8,10]] bivariate bicycle code (period 16, translation invariant) whose circuit-level distance under SD6 noise equals the code distance, d_circ = 10, for every number of rounds and in both memory bases.”
