## 我怎么做的，以及为什么相信它

我的默认立场是 E-036 错了。它最可能错在三处：自家评估器的电路/噪声约定里藏着与物理电路不符的东西；CEGAR 的 nogood 过度泛化，造出一个假的 UNSAT；Fig. S3 的重建本身不对，后面所有数字都建在沙子上。所以我做了两套互相独立、也和 E-036 独立的故障模型，再让它们彼此校验：

- **stim 模型**（`core.stim_circuit`）：自己写的 memory 电路，SD6 = 每个 CX 后 DEPOLARIZE2(p)、每层所有空闲比特 DEPOLARIZE1(p)、复位后翻转、测量记录翻转、数据初始化与读出错误；**两种类型的探测器都放**（E-036 只放记忆基底的探测器）；可选**不复位**辅助比特（Kunlun 的做法：初始化一次，X 校验每轮 H…H 再 Z 测量，探测器 m_j ⊕ m_{j−2}）。
- **符号模型**（`core.Sym`）：不用 stim，按 Pauli 传播手推的闭式故障表。Z 记忆中只需 X 部分：数据比特上的"切口"（在该比特的两个读者 CNOT 之间出现 X）、X 校验辅助比特在第 p 个 CNOT 之后出 X（扩散到后缀）、读者测量翻转、不复位时的读出翻转（s_j 与 s_{j+1} 同翻）。X 记忆对称。
  这里有一个我必须先确认的论证：在 SD6 下，任何故障的"X 投影"（把 Z 分量去掉）也是同一位置的合法 SD6 故障，Z 分量只会额外触发 X 探测器。所以 E-036 只放记忆基底探测器的做法不会让距离偏低或偏高，最小权重与放全部探测器时相同。我的 stim 模型放了全部探测器，结果与 E-036 一致，这个论证也就在数值上得到印证。
- 两个模型在所有被测电路、R = 1..5、两基底、复位/不复位上给出相同的最小权重（`a2_dcirc.jsonl`，共 80 个格子，0 处不一致）。
- 任意 R：权重 w 的不可检测逻辑最多在 w 轮里有故障；一轮没有故障时它的探测器为零意味着 s_{r−1} = s_r = H·E，删掉这一轮不改变其余探测器，所以 **R = 1..w 就决定所有 R 的下界**（比 E-036 用的 R ≤ w + 3 更紧）；反过来在最前面插一个无故障轮总是合法的，所以 R = 1 的见证给出**所有 R 的上界**。我算了 R = 1..5。

## 1. 码（`a1_code.py`）— CONFIRMED

论文原文（WebFetch）：l = m = 3，x = S_l⊗I_m，y = I_l⊗S_m，A = x^{a1} + y^{a2} + y^{a3}、B = y^{b1} + x^{b2} + x^{b3}，a = b = [1,0,2]，H_X = [A|B]，H_Z = [Bᵀ|Aᵀ]，并说明此时 H_X = H_Z。被测校验去掉 X2、X8、Z3、Z4（"to reduce experimental complexity"），[[18,6,3]] 再去掉 X5、Z5。芯片 32 个 transmon、84 个可调耦合器，"each check qubit is coupled to six data qubits"。

我用 numpy kron 独立构造：H_X = H_Z 成立；行重 6、列重 3；9 行与 E-036 抄录的 Fig. S1 逐行相同（Fig. S1 本身我看不到，这一点只能对照 E-036 的转录和"每行 6 个非零"的图注）。14 校验 rank 7+7、k = 4、d_X = d_Z = 4，与 18 校验同一稳定子群；X2、X8、Z3、Z4 都在剩余校验的行空间里；12 校验 rank 6+6、k = 6、d = 3。Tanner 边数 14 × 6 = 84（12 校验为 72），32 个比特，与论文的器件描述一致。

## 2. d_ext 与非交错上限（`a1_code.py`、`a9_nonint.py`）— CONFIRMED

我直接列出全部权重 4 的 X、Z 逻辑（各 45 个），检查 14 个被测校验的全部 210 个比特对：**210/210 都包含在某个同类型权重 4 逻辑里**。任意顺序的最后两个 CNOT 之前的辅助比特错误就是这一对的钩子，再加两个数据错误得到权重 4 逻辑；在非交错电路里同一轮的另一类校验要么全在钩子之后读要么全在之前读，所以这 3 个故障不可检测。这是一个直接构造，不依赖 SBB Cor. 1。

数值复核：非交错、按类型统一顺序（X 块在第 1–6 层、Z 块在第 7–12 层）的电路，[[18,4,4]] 720 个 X 顺序中 384 个 d = 2、336 个 d = 3，没有 4；[[18,6,3]] 中 48 个顺序到 3（72 个是 1、600 个是 2），组合后的电路 d_circ = 3。这两个计数与 E-036 表里 d_ext ≥ 3 的 336 和 48 完全相同，是用完全不同的代码得到的。

## 3. 实验电路（`a2_dcirc.py`、`a4_robust.py`、`a4b_layers34.py`、`a4c_bperms.py`）— CONFIRMED with qualifier

**距离本身。** 我按 E-036 的重建（IBM 槽位：X [—, A2, B2, B1, B3, A1, A3]，Z [A1ᵀ, A3ᵀ, B1ᵀ, B2ᵀ, B3ᵀ, A2ᵀ, —]）自己生成调度。合法（每层每比特一门，所有 X/Z 校验对的共享比特先后次数为偶）。两个模型、R = 1..5、两基底、复位与不复位：[[18,4,4]] 处处最小权重 3；[[18,6,3]] 处处没有权重 ≤ 2，有权重 3。按上面的压缩/前插论证，这对所有 R 成立。

一个小更正：E-036 说 [[18,4,4]] 的最小见证"不是单钩子 + 两个数据那种扩展码型的逻辑"。我在同一电路上找到的见证恰恰是"一个 X 辅助比特钩子 + 两个数据错误"（Z 基）和"一个 Z 钩子 + 两个数据"（X 基）。两种见证都存在，E-036 只是碰巧报告了另一种；这句话不要进邮件。

**不复位。** E-036 的论证（"读出错误把事件挪到 j、j+2，权重计数不变"）不完整：不复位时一次经典读出翻转等于复位模型里相邻两轮的两次测量错误，是一个新的、更便宜的机制，原则上可能降低距离。所以我没有接受论证，而是直接在不复位电路上算：两个模型都给出与复位版完全相同的最小权重（[[18,4,4]] 3、[[18,6,3]] 3）。结论成立，论证应改成"直接计算"。

**重建的敏感性。** 这是我认为最需要讲清楚的限定。我把 IBM 槽位标签到 Kunlun 单项式的映射全部换一遍（A 内部 6 种 × B 内部 6 种 × A/B 互换 = 72 种，全部合法）：

| 假设 | [[18,4,4]] d_circ | [[18,6,3]] d_circ |
|---|---|---|
| 72 种标签映射 | 40 个 3、32 个 2 | 12 个 3、44 个 2、16 个 1 |
| 只信第 1、7 层（逐边核对过）：X、Z 的 B 项在第 3–5 层各自任意排（36 种） | 36/36 = 3 | 16 个 3、20 个 2 |
| 信第 1、2、5、7 层，第 3、4、6 层未核对：剩下的自由度是 X 与 Z 各自的 B1↔B2（4 种） | 4/4 = 3 | 4/4 = 3 |

所以 E-036 没有逐边核对的第 3、4、6 层不影响结论，但 [[18,6,3]] "保距离"这一判断确实依赖第 5 层是 B3/B3ᵀ（以及第 2 层），而这两层只是"抽查若干边"。论文原文给出的项序（A = x + 1 + y²、B = y + 1 + x²，与 IBM 的 A1 = x^a 约定同构）支持 E-036 的映射；我看不到 Fig. S3 的图，无法自己逐边核对。**建议发邮件前把 Fig. S3 第 2、5 层的全部 14 条边逐条核对一次**；在那之前，[[18,6,3]] 那句要写成"for the circuit as we reconstruct it from Fig. S3"。

## 4. 6 层 CNOT 不可能到 4（`a3_cegar.py`、`a6_validate.py`、`a7_recheck.py`、`a8_enum_control.py`）— CONFIRMED with qualifier

**我先审 E-036 的 nogood 提取。** 我逐条读了 `cegar.py:nogood_from`：数据比特故障按读者 CNOT 相对故障时刻分成前/后两组，若故障在某个 CNOT 上则相对该 CNOT 取先后；扩散者辅助比特取前缀/后缀，并对每个后缀 CNOT 记录它与同一数据比特上读者的先后；读者辅助比特和测量翻转不产生字面量。这些字面量确实决定了该故障的探测器/观测量效果，且在模板里同效果的故障位置总存在（数据初始化、读者 CNOT 后的 DEPOLARIZE2、数据读出）。我没有找到不可靠之处。它唯一依赖、而自家评估器口径里又容易被忽略的一点是"只放记忆基底探测器"，上面的 X 投影论证说明这不影响结果。

**然后独立重做。** 我的 CEGAR 只共享"模板"这一定义，其余全部重写：SAT 变量是 one-hot 的层号（pysat Glucose4，增量），合法性与确定性奇偶直接编成 CNF；反例用符号模型精确搜 R = 1..4；nogood 用我自己的、比 E-036 更一般的字面量（数据切口只要求"前组读者都早于后组读者"，不绑定具体 CNOT，因为任意两个相邻读者之间总有一个故障位置）。

结果：**[[18,4,4]]、14 校验、S = 6：UNSAT**，52 轮、638 个 nogood、97 s。全部 638 个 nogood 都来自 R = 1，也就是说该模板里每一个合法电路**在单轮 memory 里**就已经有权重 ≤ 3 的不可检测逻辑。比 E-036 的 2,375 轮快得多，正因为 nogood 更一般；正因为更一般，我必须证明它没有泛化过头：

- 换编码、换求解器：只取 nogood 的事件级字面量，用阶梯（order）编码重建整个 CNF（1,798 变量、13,923 子句），CaDiCaL 1.5.3、MiniSat 2.2、Lingeling 三个求解器都 UNSAT；不加 nogood 时 SAT（阳性对照）。
- 换故障模型验证 nogood：60 个随机合法电路产生的 431 个 nogood，每个都另找一个满足全部字面量的**不同**合法电路（只有 1 次碰巧同一个），用 stim 全 DEM 核验同一 R 下确有权重 ≤ w 的逻辑：431/431，0 违例。
- 在可达的目标上做阳性对照：d = 3、S = 6 时枚举模式跑 CEGAR，每个"找到"的电路都用 stim 复证、存档、封掉再继续。[[18,6,3]]：41 个复证过的 d_circ = 3 电路（含 E-036 的 q1863_p8）、872 个 nogood，**没有一个 nogood 排除过任何一个好电路**；[[18,4,4]] d = 3：41 个好电路（含 bb18_p8_d3）、228 个 nogood，0 违例。过度泛化的 nogood 在这里会直接暴露。
- 18 校验全测的 S = 6 我没有复核（我的 Glucose 跑了几分钟没结论，被我按 PID 停了；不在这次要审的结论里）。

**"不可能"覆盖的模板，精确地说：** 单辅助比特（每个被测校验一个辅助比特，只用 Kunlun 的 14 个校验比特和它们的 84 个耦合器，没有旗标或额外比特）；每轮 = 全部辅助比特同一层制备、**6 层** CNOT（CZ+H 等价）、同一层测量；每个校验的 6 个 CNOT 可以任意排在 6 层里（逐校验自由，不要求各校验同序）；每层每个比特最多一个门；每轮用同一调度；**相邻两轮不重叠**（不做流水/回绕）；标准电路级去极化噪声（SD6），记忆实验两个基底。注意在 6 层、每校验 6 个 CNOT 时，"同一层制备/测量"不是额外限制（每个辅助比特都要用满 6 层），真正的限制是**不回绕**和**每轮测量一次的单辅助结构**。7 层（与实验同深度）、更深的电路、流水电路、旗标电路都不在内。

**7 层（S = 7）。** 我用同一 CEGAR 跑了两路（Glucose4 每例 8 个 nogood；CaDiCaL 每例 16 个），分别到 450 轮 / 6,084 个 nogood（58 min）和 350 轮 / 8,603 个 nogood（42 min），SAT 调用越来越慢（每轮 15–35 s），没有结论，按 PID 停。所有反例仍然在 R = 1 就有权重 ≤ 3 的逻辑，但这不是证明。7 层与 E-036 一样是**未决定**。

## 可以安全用于合作邮件的措辞

> We applied exact circuit-distance tools to the two codes of your Kunlun experiment (arXiv 2505.09684), using the code of SI Sec. I.1 and the syndrome circuit as we reconstruct it from Fig. S3 (the slot order of Bravyi et al., with 14 / 12 measured checks), under standard circuit-level depolarising noise, with and without ancilla reset.
>
> For [[18,6,3]], this circuit is distance-preserving: its circuit distance is 3 for any number of rounds. For [[18,4,4]], the circuit distance is 3, one below the code distance. For [[18,4,4]] this is largely a property of the code: every pair of qubits in a check lies in a weight-4 logical operator, so any single-ancilla circuit that measures the X and Z checks in separate blocks has an undetectable weight-3 fault (one hook error plus two data errors). Interleaving the two check types could in principle avoid this, but within a natural class it cannot: no single-ancilla circuit on your chip's couplers with six CNOT (CZ) layers per cycle, any per-check gate order, the same schedule in every cycle and no overlap between consecutive cycles reaches circuit distance 4. We have not settled the seven-layer case (your depth).
>
> What we can offer is, for each code, a circuit with one CNOT layer fewer (6 instead of 7) on the same couplers and with the same circuit distance as yours. In our simulations with your Tab. S1 error rates, it lowers the per-round logical error rate of the code block by about 3–7%; at ten times lower physical error rates the reduction is about 15–25%, except in the X basis of [[18,4,4]], where we see no significant difference. 和 E-036 草稿相比我改了这些：
1. "your circuit" → "the circuit as we reconstruct it from Fig. S3"（第 3 节的敏感性）；在第 2、5 层逐边核对之前不要去掉这个限定。
2. "This is a property of the code, not of your circuit" → "largely a property of the code"，并把"separate blocks"写清楚。说"不是你们电路的问题"会被读成"任何电路都到不了 4"，而交错电路的 7 层及以上没有定论。
3. "we proved that no single-ancilla circuit with 6 CNOT layers … reaches 4" 补上"任意逐校验顺序、相邻周期不重叠"；删掉"our searches with 7 layers found none"：7 层的搜索在 E-036 和这次审计里都没有结论，这句话会被读成比实际更强的证据，不如直说没有定论。
4. LER 的 ×0.1 范围写出例外；写明是码块每轮错误率（不是论文的每逻辑比特错误率）。
5. 删掉"cross-checked by two independent implementations"里的"两个"之类可能引人追问的细节，改为"reproduced by an independent implementation"。

## 发现的问题（都不推翻结论）

1. 不复位等价的论证不完整（读出翻转是复位模型里的两个故障）。结论经直接计算成立；日志应改为"直接计算"。
