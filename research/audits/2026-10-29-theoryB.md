## 1. 定理 1：台阶配对模型 —— CONFIRMED

**证明。** 论证正确，但正文只写了“用 SM S2 的 (a)(b)(c)”，漏了一步：SD6 的每个单故障分量都必须恰好对应模型里的一个故障。我逐类核对过，都成立（以 Z 基底、X 型误差为例）：
- X 校验的 CNOT（辅助比特控制）后的 X_a X_q 等于该 CNOT 之前的 X_a，也就是从第 k 个 CNOT 开始的钩子；单独的 X_a 是从第 k+1 个开始的钩子；单独的 X_q 是数据误差。
- Z 校验的 CNOT（数据控制）后的 X_q X_b 等于 CNOT 之前的 X_q，即读之前的数据误差；单独的 X_b 等于测量翻转。
- 复位 / 测量 / 空闲故障分别等价于：时刻 0.5 的数据误差、最后一层之后的数据误差、测量翻转、钩子。RX 之后辅助比特上的 X 就是 k = 1 的“钩子”，签名为空。

论文里应把这张对应表写出来，否则“三类单故障”只是断言。

**计算。** `dem_check.py` 不用 `unroll`，也不读 spec，模型直接从评估器生成的无噪声 stim 电路逐层解析出来：每个辅助比特的实例、CX 时刻、测量时刻，以及有限 R 的指标 = 该实例之前读过的次数。然后把模型的签名集合和 SD6 DEM（`approximate_disjoint_errors`，不分解）的签名集合逐个比较。决定距离的正是签名集合。结果全部相等：

## 2. 引理 2 / 命题 3 —— CONFIRMED，表述要改

**良定义。** 引理 2 的理由正确：RX 之后、第一个 CNOT 之前辅助比特上的 X 作用在 |+⟩ 上是恒等，所以 k = 1 的沉积不触发任何探测器，也就是每对 (c, z) 共享比特上的指标两两配对。`delta.py` 对 10 个电路两基底都核过，配对违例为 0。|Q| = 2 时 δ 是一个整数。

**δ 的值（我的计算，Z 基底）。**

| 电路 | δ | 上边缘？ | 按项对 (A_i, B_j) 的 3×3 矩阵 |
|---|---|---|---|
| u11 | 0×216，−1×432 | 否（250 条边违例） | δ = −[j ≠ B1] |
| c11 | 0×135，−1×270 | 否 | δ = −[i ≠ A2] |
| IBM depth-8 gross | 0×216，1×432 | 否 | δ = [i ≠ A2] |
| bb108 模板 | 0×162，−1×324 | 否 | δ = −[j ≠ B1] |
| segctl | 全 0 | 是 | — |
| ctl_p10 / u16 / c16 | 0/1 | 否 | — |

X 基底下 u11 的 δ 是 1×216、2×432，只差一个常数，结论相同。文中表格的数字全部对上。“平移不变的 δ 是上边缘 ⇔ 9 个值相等”的证明（对平移群求和）正确。

**命题 3 的证明。** (a) 是按定义得到的等价，正确。(b) 也正确：δ' ≡ 0 时，q 的每个 X CNOT 时刻 τ 都落在 ∩_z (ρ'_z − P, ρ'_z) 内，所以 τ − ½ 处的数据误差在所有读者上的指标都是 0；钩子实例取 a_c；每个读者收到的项数等于 (H_Z S)_z 加上偶数，并且全是同一个值。

计算核对：segctl 体内 144/144 全部提升，平移量全是 0。

**要改的 4 处：**
1. **bb18 的事实错误。** 正文说“5 对校验共享 4 个比特”。直接算 HX·HZᵀ 得到：重叠 6 的有 5 对（X、Z 支撑完全相同），重叠 2 的 32 对，重叠 0 的 12 对。这 5 对的 δ 取两个值，所以 δ 在 bb18 / Kunlun 上不是一个 1-余链，表里这两行的“上边缘？否”没有意义。要么推广 δ 的定义（比如取多重集或模 2 的类），要么在表中删掉这两行的判定。
2. **“SBB Cor. 1 的两行证明”说过头了。** 命题 3(b) 只是体内命题。SBB 的 Cor. 1 对所有 R 成立，针对的是非交错电路（“either all X-type CNOTs precede all overlapping Z-type CNOTs …”），对应的是评估器标号下 δ 为常数、势全为 0 的情形。这时取同一轮的钩子，任何 R 都能实现，确实能推出有限 R 的版本。但对一般的可分段（流水）电路，势 a_c 各不相同，有限 R 要求这些实例存在，还要满足窗口条件。建议写成“体内版本，以及 SBB 非交错情形下对所有 R 的版本”。
3. **IBM 的扭转形状。** IBM 的扭转在 A2 上（行），和 c11 的位置相同、符号相反（模上边缘：IBM ≡ −[i = A2]，c11 ≡ +[i = A2]）。它不是“与 u11 一样”的 B1 扭转。第 3 节末尾的“扭转必须和顺序类配合”这个论点不受影响，但描述应改准。
4. **摘要第 2 条的措辞。** “IBM depth-8 与 Kunlun … 距离却都停在 d_ext 以下或等于 d_ext”不对：d_circ ≥ d_ext 恒成立（SBB Prop. 3）。而且 Kunlun 在 Z 基底 d_ext = 2、d_circ = 3，是 d_circ > d_ext 但 < d 的例子。要表达的意思是“δ 非上边缘不足以给出 d_circ = d”，这一点成立，换个说法即可。

## 3. 引理 4（窗口引理）—— CONFIRMED（包含形式），“相等”要改

**证明。** 有限指标 = #{t ∈ 0..R−1 : read_t < u}（R 时即最后的数据读出），体内指标 = #{t ∈ ℤ : read_t < u} 减去 t < 0 的部分。所有沉积时刻 u ∈ [½, last + ½]。由 (Wb) 有 read_{−1} ≤ 0 < u，体内指标 ≥ 0；由 (Wt) 有 read_R ≥ last + 1 > u，体内指标 ≤ R。两者相等。这个证明本质上是一行。

结论应写成**有限 R 的不可检测故障集嵌入体内**（有限 ⊆ 体内），而不是“就是”体内的集合。反方向一般不成立：体内可以用 0..R−1 以外的写者实例，有限电路里没有这些实例。定理 5 只需要包含方向，所以证明链没有断。

(Wb)、(Wt) 与 R 无关，我按代码核过：`unroll` 选的 σ 最小化 D(R−1) + max(start + dm)，argmin 与 R 无关；两个条件都化成与 R 无关的不等式。

**计算（`window_test.py`，用评估器 `unroll` 的起点，逐个沉积比较有限指标与体内指标）：**
- u11、c11、bb108 模板、bb18_n8_d4、IBM8、segctl、u16、c16、Kunlun：R = 1..3、两基底，(Wb)(Wt) 都成立，不一致 0 处。
- ctl_p10：X 基底 (Wt) 不成立，不一致 72 处，与文中一致；Z 基底成立。即使在 (Wt) 不成立的 X 基底，w11 列表上有限 R = 1、R = 2 的提升（576 个）也和体内提升的 576 个**完全相同**；Z 基底 R = 1 是 432 = 432。
- 40 个随机合法且确定的调度（u11 的顺序类，周期 8–14，用我自己的模板生成器）：80 个“调度 × 基底”实例里，**61 个窗口条件不成立**（(Wb) 或 (Wt) 失败，不一致 72–648 处）。窗口成立的 19 个，不一致全部为 0。所有实例上有限 R = 1 的 w10(+1) 提升都包含在体内提升里。但这些随机调度在体内把 144 个全部提升，所以这一项检验是空的。
- 在 u11 附近做小扰动来找“体内 0 提升、窗口不成立”的电路：扰动后几乎全部不合法或不确定，没找到。

**判断。** 引理本身正确。但窗口条件在一般调度上经常不成立（随机样本里约 3/4），所以判据不是一般适用的，每个电路都要单独核对。目前没有找到“窗口不成立 ⇒ 有限比体内多出提升”的实例，所以我无法说明这两个条件是必要的，只能说它们是证明需要的充分条件。

## 4. 定理 5 判据、定理 6 / 推论 7 —— CONFIRMED（d − d_ext ≤ 2），一般陈述不完整

**归约正确。** 设 F 是有限 R 下的不可检测逻辑故障集，|F| ≤ d − 1。由引理 4，F 嵌入体内。把每个故障映到它的列（H 像 ‖ L 像），奇数重的列构成 S。S 的 H 和为 0，L 像等于 F 的 L 像，不为零，所以 S 是扩展码逻辑，|S| ≥ d_ext。F 的其余故障分三类：零像故障（测量翻转，以及签名为空的 k = 1 钩子）、成对的相同列、三重及以上的重复（等于 S 中一列加若干对）。所以 |F| = |S| + z + 2c。我核了“零像只有测量翻转”这一条：u11、c11、bb108（两基底）的 k = 2..6 钩子中 H‖L 像为零的都是 0 个。

**“相同列对”在 d − d_ext ≤ 2 时无关，成立。** 一对相同列让权重至少到 d_ext + 2 ≥ d。所以 u11（10/12）、c11（8/10）、bb108（8/10）、bb18（2/4）都只需要检查：权重 d_ext 加至多 1 个翻转，以及权重 d_ext + 1。翻转的数目也只到 1，同一读者上放两个翻转的情形不会出现。

**一般陈述的缺口**（d − d_ext ≥ 3 时）：
- (i) 相同列对的那一列可以是 S **以外**的任意扩展码列。正文局限一节承认 `small.py` 只枚举了 S 内部的列，但定理 5 的陈述里没有这个限制。
- (ii) d − 1 − w ≥ 4 时可以有两对以上，陈述里只写了“一对”。
- (iii) 翻转可以有两个以上，也可以在同一读者上。
- (iv) |S| ≥ d_ext + 3 时，列表必须包含可约集合，即逻辑与零像平凡集合的并。“遇到 H 和为 0 就停”的 DFS（E-014 的和我的都是）在 |S| < d_ext + 3 时才完备。证明：若 S = T ∪ (S∖T) 都是零 H 和，其中一部分是逻辑，权重 ≥ d_ext；另一部分是非空的平凡零 H 和集合，权重 ≥ 3，因为不存在零像列，而 H 像相同的两列 L 像必不同，否则就是同一列，那样会构成权重 2 的逻辑。

建议在定理 5 的陈述里直接加上假设 d ≤ d_ext + 2，或者把 (i)–(iv) 补全。

**定理 6 / 推论 7。** 固定分支后，提升是一组 x_a − x_b = c 型的等式，加上数据列的台阶约束。台阶约束我核了：读者按时刻循环排序为 1、2、3 时，允许的指标向量恰好是 y1 ≥ y2 ≥ y3 ≥ y1 − 1 的整数解，正好 3 个切口，是差分约束。差分约束可行 ⇔ 无负环，这是标准结果。两钩子证书正确，并且和乐 ≥ 2 时能扛住一个翻转（翻转只能把某一读者的等式放宽 ±1）。

自己的复核（`twohook.py`）：u11 Z 基底 w10 的 144 个全部有和乐 = 2 的两钩子证书。列表第 0 个的证书是钩子 (X45, k = 3，后缀长 4) 与 (X59, k = 5，后缀长 2)，与图 1(b) 一致。
