## 逐项

### 1. 合法性（`b1_legal.py` → `b1_legal.json`）

- **是 gross 码本身**：按 arXiv:2308.07915 的多项式 l = 12、m = 6、A = x³ + y + y²、B = y³ + x + x²，自建
  HX = [A | B]、HZ = [Bᵀ | Aᵀ]（下标 i = 6·(x 指数) + (y 指数)），与评估器 `build_code("gross-dcirc")` 的 HX、HZ
  **逐元素相等**（不是置换后的等价码）。n = 144，k = 144 − rank HX − rank HZ = 12，HX HZᵀ = 0。d = 12 是文献值（同一 arXiv）。
- 自查调度：72 + 72 个校验，每个恰好 6 个 CNOT、列集合 = 该行支撑、辅助比特时刻互异、全部在 (prep, meas) 窗口内；
  同一时刻同一数据比特至多一个 CNOT：0 个问题。period 38，所有校验 prep = 0、meas = 37（不回绕帧）。
  评估器 `validate_schedule`：0 个问题。评估器模板本身保证单辅助比特（每行一个专用辅助比特、每轮 R—CX×6—M）。
- 确定性：R = 1、2、3、6 两基底 `detector_error_model()` 不报错；无噪声采样 64 次，0 个探测器、0 个 observable 响。
  L0（任务 gross-dcirc 的模板约束，不含距离项）R = 2、3 两基底全部通过。
- 交错：每个数据比特一个周期内的 X/Z CNOT 类型序列（循环）切换次数：96 个 2 次、48 个 4 次，确实交错
  （按 Strikis Prop. 4，非交错电路到不了 12，所以必须交错）。

### 2. 扩展码不变性（`b2_ext.py` → `b2_ext.json`）

推导（Strikis 的残余后缀）：Z 基 memory 只看 X 错。X 校验 CX(辅助→数据)，辅助比特第 k 个 CNOT 后的 X 错传到
后缀 {q_{k+1},…,q_6}；Z 校验 CX(数据→辅助) 不改变数据上的 X 帧。所以单个故障在末端的数据 X 帧要么是 0，要么是
一个数据比特，要么是某 X 校验顺序的一个真后缀；列 = 它的 (H_Z s, L_Z s)。后缀长 5 ≡ 首元素（乘稳定子），
长 4 ≡ 前两个，长 3 = 后三个 ≡ 前三个的补，长 2 = 后两个。所以列集合只取决于每校验 (前两个, 前三个, 后两个) 三个**集合**；
整体反转把 (前两, 前三, 后两) 变成 (后两, 后三, 前两)，像不变；位置 1–2、5–6 内互换不改集合。X 基对称。
计算核验：
- 144 个校验与 E-018 审计读出的 Fig. 12 顺序比较：**144/144 是“反转 + 对内互换”**，0 个相同、0 个其他。
- 自算扩展码（数据列 + 全部真后缀，去零、按键去重）：两侧 N = 360，**键集合与 Fig. 12 的相等**，也与 E-018 审计
  `a2_stage_a.build` 的相等。所以 d_ext = 11（E-014）和完整 4224 列表（E-018）原样适用。

### 3. lift 归约是否适用（Table I、完备性）

论证（不需要 Prop. 3 的单辅助比特结构，也不受交错影响）：对 DEM 增广 observable（末端数据读出上每行 H、L 各一个）。
(i) 每行 H_i 的增广 observable 恒等于该校验全部探测器之和（模板：首轮 + 相邻轮比较 + 末端），所以任何不可检测的
故障集合像的 H 部分之和为 0；observable = L 部分（逐项断言 ob = lb）。(ii) 每个非零像是扩展码的一列（Table I）。
于是权重 w 的不可检测逻辑给出一个权重 ≤ w 的扩展码逻辑；d_ext = 11 ⇒ w ≥ 11，且 w = 11 时 11 个像非零互异、
组成完整列表中的某一个。原 DEM 的项是增广项的并，所以原 DEM 的最小权重 ≥ 增广下的结论。
计算核验（`b_common.dem_groups`，自写）：R = 1..20（b2 做了 1..6，b3 每次运行都断言）两基底：
`telescoping_bad = 0`（每个 DEM 项的逐校验探测器奇偶 = 像的 H 部分），`bad_obs = 0`，**像的键集合 = 扩展码 360 列（等号，不只是子集）**。
需要注意的范围：d_circ 按 DEM 机制计数；Z 基 memory 的 DEM 只含 Z 校验探测器（模板不放 X 校验探测器），
探测器越少不可检测集合越多，所以这里的下界对“全部探测器”的定义同样成立。

### 4a. 精确：没有权重 ≤ 11（`b3_lift.py`、`b4_mitm.py`）

- 方法一（b3）：对每个权重 11 扩展码逻辑 S（**E-018 审计**自己的 DFS 输出按 24 元群展开，4224 个/侧），CP-SAT
  判定“每列恰选一个 DEM 项、探测器异或为 0”是否可行（ExactlyOne + 每个探测器 BoolXOr）。
- 方法二（b4）：无求解器的折半穷举（11 列分两半，枚举全部异或，求交）。
- 阳性对照：Fig. 12 本身 Z 基 R = 1、X 基 R = 1、2 → **4224/4224 提升**（两种方法都是），与 E-018 一致。
- 候选：

| 基底 | R | b3 CP-SAT | b4 MITM |
|---|---|---|---|
| Z | 1..14、16、20 | 全部 0/4224 | R = 1、2、3：0/4224 |
| X | 1..14、16、20 | 全部 0/4224 | R = 1、2、3：0/4224 |

与实验者 `lift_cand1_R1-6.json`（R = 1..6 两基底 0/4224）一致；我把范围扩大到 R ≤ 14、16、20。

### 4b. 不经 lift 的独立下界（UNVERIFIED）

直接在整个电路 DEM 上求最小权重逻辑（不用扩展码、不用列表），R = 1、Z 基（864 个机制、144 个探测器）：
- 评估器 `lower_bound(method="maxsat")`（RC2，stim 的 shortest_error_sat_problem）：**7200 s 超时**，无结论；
- 评估器 `lower_bound(method="cpsat", target=12)`：**3600 s UNKNOWN**，下界只到 0。
所以“d_circ ≥ 12”目前只有经 lift 归约的证明（4a、两种独立实现），没有绕过 d_ext = 11 和 4224 列表的第二条证明路线。
这两项是本结论剩下的外部依赖（都已在 2026-10-05 / 2026-10-08 审计中独立复核过）。

### 4c. 启发式攻击（`b8_ub.py` → `b8_ub.jsonl`）

评估器 `upper_bound`（stim 截断搜索 size/degree 4 + 400 次 BP-OSD + LNS），种子 777（实验者用 20261010）：
R = 1、2、3、7、10，两基底，**10/10 最好都是 12**（stim_search 和 bposd 都给出 12），没有任何 ≤ 11 的见证；
低权重直方图里权重 12 的不同逻辑每次 5–49 个。只是佐证，不是证明。

### 5. 上界 12（`b6_inject.py` → `b6_inject.json`）

CP-SAT 求权重 12 的 X 型（Z 型）数据逻辑：Z 基支撑 {4,51,52,55,58,60,64,70,125,126,127,142}，X 基
{3,5,19,20,21,22,39,41,55,56,57,58}。作为数据复位后的翻转（SD6 里每个都是一个故障机制）以概率 1 注入
评估器的无噪声电路：R = 1、3、6、10 两基底 **0 个探测器、observable 翻转**；去掉其中一个则被检测。所以 d_circ ≤ 12。

### 6. 任意 R

前提（`b7_periodic.py` → `b7_periodic.json`，全部 true）：
- 轮次分隔：展开后第 k 轮全部 144 个辅助比特在第 38k 层复位、38k+37 层测量，所有 CNOT 严格在两者之间；窗口 [38k, 38k+37] 铺满时间轴。
- 周期性：SD6 带噪电路（含空闲噪声）第 1..12 轮的层逐层相等（第 t 层 = 第 t+38 层）；R = 7 电路 = R = 6 电路在第 1 轮后插入一个 38 层块。只有第 0 轮第 0 层（数据复位）与后面不同。
- 探测器 = 首轮 + 同校验相邻轮比较 + 末端（坐标检查）。
证明：
1. 对任意 R，Table I 与像集合 = 360 列（每轮的故障位置与像相同，已算到 R = 20），所以 4a 的归约对任意 R 成立：权重 ≤ 10 不存在。
2. 分裂引理：设 F 是权重 11 的不可检测逻辑，第 r 轮（严格在 F 的首、末轮之间）没有 F 的故障。令 F_< 为 r 轮之前的故障。
   只有 F_< 时，从第 r 轮复位起数据帧恒为 e，此后各轮都测 H e，比较 ≥ r 轮的探测器和末端探测器都为 0；
   只有 F_> 时，第 ≤ r 轮的测量都不受影响。线性 ⇒ F_<、F_> 各自不可检测，observable 之和非零 ⇒ 其中一个是权重 ≤ 10 的不可检测逻辑，矛盾。
   所以 F 占的轮连续，跨度 ≤ 11 轮。
3. 平移：若 F 在长电路的 [a, b] 轮，b − a ≤ 10，构造 R' 轮电路：a > 0 时在前面保留一个干净轮，b < R − 1 时在后面保留一个干净轮。
   F 涉及的探测器值只由 [a−1, b+1] 内的层决定，周期性保证这些层与 R' 电路对应层相同（干净的第 0 轮有数据复位，但 F 在那里没有故障、帧为 0）。
   所以 R' ≤ 13 的电路里有对应的权重 11 不可检测逻辑。R = 1..13 已精确排除（4a）⇒ 任何 R 都没有。
结论：**d_circ = 12 对所有 R ≥ 1、两个基底成立。** 第 2、3 步是书面论证（与 E-015 B7 同型，结构前提已机器核验），第 1 步和 R ≤ 13 是计算。
（b ≤ 10 而 R 很大时用前后各一个干净轮，R' ≤ 13；贴边界时 R' ≤ 12。）

### F3. 任意 R 论证的人工复核（实验者 `anyR.py`，R' ≤ 14 的“删轮”版本）：**CONFIRMED**

- 实验者的版本：a ≥ 3 时删去无故障的第 2 轮（前后都是无故障、数据帧为 0 的测量），b 之后保留一个干净轮再删去其余轮 ⇒ R' ≤ 2 + 11 + 1 = 14。
  我逐条核过：被删轮两侧的比较探测器 det(c, j) = m_j ⊕ m_{j−1}，删前删后两侧测量值都是 0（a 之前）或都是 H e（b 之后），值不变；
  末端探测器（数据读出 ⊕ 最后一轮）在 b 之后恒为 H e ⊕ H e = 0。正确，只是比我的版本保守一轮（我证明 a 之前只需留一个干净轮，
  因为首轮探测器 = m_0 与“干净轮比较” m_a ⊕ 0 取值相同）。两种版本需要的 R'（13 或 14）都已精确覆盖。
- “评估器把 DETECTOR 全放在电路末尾、跨插入点的探测器要整体后移”：这只是**按下标**对应探测器时的记账问题。论证本身按语义
  （探测器 = 同一校验相邻两轮测量之和，由坐标 (校验, 轮) 标识）进行，与 DETECTOR 指令在文件中的位置无关。我用坐标核对了
  探测器集合 = {(i, j) : i < 72, 0 ≤ j ≤ R}（b7 的 det_coords_complete），再加上评估器模板代码（`memory_circuit`）的读码：
  第 j 轮的 detector 就是 rec(q, j) ⊕ rec(q, j−1)。实验者“中途两次失败是核对脚本问题”的说法与此一致，不是电路问题。
- 分隔引理里“轮”的划分：不回绕帧下所有辅助比特同层复位、同层测量，层窗口 [Pk, Pk+P−1] 铺满时间轴，数据比特的空闲/复位故障
  按层归轮，没有歧义（cand1、cand1c、cand_p21 都核过）。
