**交错**（`a1b_interleave.py`）：
- 每个数据比特一个周期内的循环序列只有两种：L 比特 `ZXXXZZ`（步 0..5），R 比特 `XXZZZX`（步 4..9），即循环地 XXX 接 ZZZ，只有两次切换。所以周期内没有“层内穿插”。
- 但电路不可分段。我建了实例先后图：节点是校验实例 (类型, 校验, 轮)，同一数据比特上一个 X-CNOT 先于一个 Z-CNOT（或反之）就连边；同类 CNOT 在数据比特上对易，不连边。可分段电路要求存在“块号”使边不降、跨类型的边严格升，所以**含两种类型的强连通分量**就证明不可分段。u11 在 R = 2、6 都有，每个分量 144 个实例（同一轮标号的全部 72 个 X 和 72 个 Z 实例），最短见证 6-环：X9 → Z17 → X12 → Z20 → X22 → Z24 → X9（同一轮）。对照：把同样的每校验顺序改成“X 块（1..6）后 Z 块（8..13）、周期 15”的分段电路，图里没有混合分量，路径上的类型切换数 ≤ 2R − 1。
- 所以“交错完全来自流水（回绕）”的说法成立，精确的意思是：每个数据比特在一个周期里先连续做三个 X-CNOT 再连续做三个 Z-CNOT，但一个 Z 校验族实例的三个 CNOT（B1 在一个周期的步 0，B2、B3 在步 4、5）跨过了下一轮 X 实例的步 1..3，所以无论怎样重排对易门都分不成 X 块、Z 块。这与 d_circ = 12 > d_ext = 10 一致（可分段电路 d_circ ≤ d_ext，SBB Cor. 1；那是引用，我没有重证）。

**零像机制**（`a3_lift.py`，DEM 加上 H 行、L 行的“像 observable”）：R = 1..31 两基底（第 4 节的全部运行），像为 0 且带探测器的 DEM 项**恰好 72R 个，全部是 {(c, j), (c, j+1)} 的读出翻转模式**；像为 0 而不带探测器的项 0 个；没有其他零像项。加了像 observable 之后的项数与原 DEM 项数相同（864、1584、2304……），所以**每个 DEM 项的像唯一**，合并不会把不同像的故障并在一起。物理上的其他零像故障（例如 X 辅助比特第一个 CNOT 之前的 X，传播成整条 X 稳定子）对 Z 测量不可见（确定性 = 每对重叠实例的先后次数为偶数），没有探测器，所以不出现在 DEM 里；Z 辅助比特上实例中途的 X 只翻转测量，与读出翻转同一签名。lift 的零像组不靠这段物理描述：它把 DEM 里所有零像项都收进候选。

## 2. 推广的引理 2：CONFIRMED（自己重推）

设 F 是 R 轮电路里一个不可检测、翻转逻辑的 DEM 项集合，|F| = w。由 Lemma 1（Table I，我在 R = 1..31 两基底逐项断言：每个非零像都是我的扩展码的一列，360 列全部被实现）每项的像是 0 或一列。伸缩恒等式（每项、每个校验 c，c 各轮探测器的 XOR = 像的 H 部分第 c 位）我在同样的 R 上逐项断言，0 违例；circuit observable = 像的 L 部分，也逐项断言。

z 个零像项；非零像按列分组，列 j 出现 m_j 次，c = Σ⌊m_j/2⌋。奇数次出现的列组成 x，|x| = Σ(m_j mod 2) = (w − z) − 2c。F 不可检测 ⇒ x 的 H 部分和为 0（伸缩）；x 的 L 部分和 = F 的 observable ≠ 0。所以 x 是扩展码逻辑，|x| ≥ d_ext = 10，即 **z + 2c ≤ w − 10**。

- w ≤ 9：不可能。
- w = 10：z = c = 0。10 项像两两不同、非零，组成**权重 10 扩展逻辑**（w10 列表里的一个）。
- w = 11：z + 2c ≤ 1 ⇒ (z, c) = (0, 0)：11 个两两不同的非零像，**权重 11 扩展逻辑**；或 (1, 0)：10 个两两不同的非零像组成**权重 10 扩展逻辑** + **恰好 1 个零像项**。c ≥ 1（两项同像、或同一列三项）都使 |x| ≤ 9，不可能；z = 2 也不可能。

情形完整，没有遗漏。lift 正是按这三类做的：每列恰选一项，(1, 0) 情形再恰选一个零像项（只需考虑探测器包含在各组支撑并集内的零像项，并集外的探测器无法抵消）。

## 5. 任意 R 的间隙论证：CONFIRMED

前提（`a6_anyr.py`，自己的展开；插块性质也在评估器电路上核）：
- 起点与 R 无关（R = 1..40）：s_q ∈ {0, 1}，S = 1；dm_q = 10 = D − 1（所有校验）；实例内最后一个 CNOT 偏移 9 = D − 2；END = max_q(s_q + 11(R−1) + dm_q) + 1，且 END ≤ s_c + 11(R−1) + S + dm_max + 1 对每个 c 成立；第 0 轮测量最晚在层 11。
- 插块：R − 1 轮电路在层 x 插入 11 层得到 R 轮电路，当且仅当 x ∈ [1, 11R − 11]（含噪层串逐层比较；我的电路 R = 2..16、评估器电路 R = 2..12，两基底，区间连续）。与项目 anyr 日志一致（lo = 1、c_hi = −11）。

论证（我逐步重推，记 a = F_< 最后故障层、b = F_> 最早故障层）：
1. 沉降：F_< 的故障都在 ≤ a 层，只有在途辅助比特还能改数据，经它本实例剩下的 CNOT，都在 ≤ a + 9 层，所以数据帧从 a + 10 = a + D − 1 起不变（= e）；复位在 ≥ a + D − 1 的实例无故障，测得 H_c e。
2. 分裂：比较探测器 (c, j) 同时响应两部分，需 s(c, j−1) < a + D − 1 且 meas(c, j) = s(c, j−1) + D + dm_c ≥ b，即 b − a ≤ 2D + dm_max − 2 = 30；末轮探测器 (c, R) 需 s(c, R−1) < a + D − 1 且 b ≤ END ≤ s(c, R−1) + S + dm_max + 1，即 b − a ≤ D + S + dm_max − 1 = 21；首轮探测器 (c, 0) 响应 F_> 需 b ≤ 11，而 a ≥ 0，所以 b − a ≤ 11（这里按 revg 审计的更正写，不是“analogous”）。所以 b − a ≥ G = max(2D + dm_max − 1, D + S + dm_max) = max(31, 22) = **31** 时两部分的综合征不相交，各自不可检测，其一翻转逻辑。
3. 归纳顺序：(0) Table I + d_ext = 10 ⇒ 任意 R 无权重 ≤ 9（Table I 是逐故障的结构性质，与 R 无关；R ≤ 31 我也逐项断言了）。(1) 权重 10：若相邻故障层有间隙 ≥ 31，分出的一部分是权重 ≤ 9 的逻辑，矛盾 ⇒ 跨度 ≤ 9 × 30 = 270。(2) 权重 11：分出的一部分是权重 ≤ 10 的逻辑，与 (0)(1) 矛盾 ⇒ 跨度 ≤ 10 × 30 = 300。先 10 后 11，没有循环依赖。
4. 删块：前端在 x + D ≤ f_1 处删（之前无故障），直到 f_1 ≤ lo + D − 1 = 11 ⇒ f_last ≤ 11 + 300 = 311；后端在 x ≥ f_last + 2D − 1（anyr.py 用的；2D − 2 也成立）且 x ≤ 11R − 11 处删，跨切口的探测器 = 原两个探测器之和，帧相同。停下时 11R − 11 < f_last + 21 ≤ 332 ⇒ **R ≤ 31**（2D − 2 版本同样 31；权重 10 只需 R ≤ 28）。
5. R ≤ 31 的两基底 lift 全 0（第 4 节，我自己的实现；项目另有 DP 和 CP-SAT 两套）。删块可能让两个故障落到同一 DEM 项而互相抵消，但那只会得到更低权重的不可检测逻辑，同样被 R' 处的结论排除。

⇒ 任意 R、两基底无权重 ≤ 11。

## 论文可用措辞

- 主结果：“We give an explicit single-ancilla syndrome-extraction circuit for the gross code [[144,12,12]] with period 11. It is translation invariant (all X checks share one CNOT order and timing, as do all Z checks) and pipelined: each Z-check window wraps across the period boundary. Under SD6 noise its circuit-level distance equals the code distance, d_circ = 12, for every number of rounds and in both memory bases.”
- 交错：“Within one period every data qubit performs its three X-check CNOTs and then its three Z-check CNOTs; the circuit is nevertheless not segmentable, because a Z-check instance straddles the next X-check instance on the same data qubit (pipelining).”
- 证明：“With the CNOT order class A1A2A3B3B1B2 the extended code has d_ext = 10, with exactly 144 weight-10 and 7344 weight-11 logicals per basis. Every fault's residual is trivial or a single extended column, so an undetected logical of weight 10 is a lifted weight-10 extended logical, and one of weight 11 is either a lifted weight-11 extended logical or a lifted weight-10 extended logical plus one ancilla readout flip (the only faults with trivial residual that trigger detectors). We exclude all such lifts exactly for R = 1, …, 31 rounds, and a gap argument reduces every R to R ≤ 31. A direct search over the full detector error model confirms that the minimum weight at R = 1 is 12 without using the extended code.”
- 不能说：逻辑错误率改善、与 IBM 深度相同、列表完备性有证书、文献无先例（未查）。
